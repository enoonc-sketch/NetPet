# NetPet 1.5.0

Windows 桌面智能宠物：用 3D 小宠物显示网速和电脑状态。**没有服务器，不收集、不上传你的任何数据；默认设置下完全不联网。**

> **会联网的功能只有 7 个，全部默认关闭或需要你点击：** 解析主机名（反向 DNS，默认关）· 真实联网检测（默认关，请求微软联网检测地址）· 系统更新在线检查（点击才查，由 Windows 更新服务完成）· 驱动更新在线检查（1.5.0，点击才查，同样由 Windows 更新服务完成）· 更新病毒库（1.5.0，点击才更新，由 Microsoft Defender 联系微软）· 检查 NetPet 新版本（点击才查，访问 GitHub）· VPN（点击才连，流量交给**你自己配置的** sing-box 服务器）。
> **会修改系统的功能也都需要你点击或开启（自动类的全部默认关闭）：** 开机自启 · 系统清理（删除不可恢复）· 启动管理（可恢复）· VPN 系统代理（断开即恢复）· 运行内存整理（不关闭程序）· 任务管理器（1.5.0，唯一能结束进程的功能，每次确认，系统 / 杀毒进程受保护）· 磁盘整理（1.5.0，调用系统 Optimize-Volume，SSD 只做 TRIM）· 温度与节能（1.5.0，电源方案 / 最大处理器状态，先备份可恢复）· 病毒查杀（1.5.0，只发起 Microsoft Defender 扫描，离线扫描会重启电脑）。
> 详见 [`docs/隐私数据流审查.md`](docs/隐私数据流审查.md)。

## 运行 / 打包
```
双击 build.bat        （一键安装依赖并打包安装版；网络慢用 build-cn.bat）
npm install && npm start   （开发运行，需要 Node.js 22.13 及以上）
npm test                    （单元测试，最后一行应输出 all tests ok）
npm run typecheck           （TypeScript 类型检查）
npm run check               （类型检查 + 单元测试）
npm run dist:all            （同时打安装版和便携版）
```
打包产物在 `dist/`：`NetPet-Setup-1.5.0.exe`（安装版）、`NetPet-1.5.0-portable.exe`（便携版）。
详细文档见 `docs/`：使用说明、技术架构、测试报告（含尚未在 Windows 实测的部分）、发布前测试清单、排障说明、隐私数据流审查。更新记录见 `CHANGELOG.md`。

### 持续集成与发布（GitHub Actions）
- `.github/workflows/ci.yml`：每次推送 / PR 在 `windows-latest` 上安装依赖 → 类型检查 → 单元测试 → 打包（不签名），产物作为 Actions 附件保留 7 天。
- `.github/workflows/release.yml`：推送 `v*` 标签（如 `git tag v1.5.0 && git push --tags`）时构建安装版 + 便携版，生成 `SHA256SUMS.txt`，创建**草稿** Release，确认后手动发布。会先核对标签与 `package.json` 版本号一致。
- **代码签名（可选）**：在仓库 Settings → Secrets 添加 `CSC_LINK`（.pfx 证书的 base64 或 https 链接）和 `CSC_KEY_PASSWORD` 即自动签名；不配置就生成未签名的包。本地默认不签名（`build.bat` 里 `CSC_IDENTITY_AUTO_DISCOVERY=false`，`signAndEditExecutable=false`），想本地签名可设置同名环境变量后运行 `npx electron-builder --win nsis portable -c.win.signAndEditExecutable=true`。
- **关于 package-lock.json**：源码包里没有锁文件（打包环境无法联网安装）。第一次在本机 `npm install` 后请把生成的 `package-lock.json` 提交到仓库，CI 会自动改用 `npm ci`，保证每次构建用的依赖版本一致。

## v1.3.3 更新（功能审查修复）
**新增**
- **检查 NetPet 新版本**：设置页 → 关于 →“检查新版本”，点击才访问 GitHub Releases 一次；有新版本时给出发布页链接，不自动下载或安装。
- **流量额度提醒**：设置每月流量额度，用到 80% / 100% 时宠物和通知提醒，概览页显示用量进度。
- **新程序首次联网提醒**（默认关闭）：基于连接记录，先学习 24 小时，之后有程序第一次连外网就提醒。
- **久坐 / 喝水提醒**：按实际使用电脑的时间计时，勿扰/全屏时不打扰，宠物气泡和通知一起提醒。
- **硬盘健康（SMART）与电池健康**：加入系统健康检查，只读 Windows 自带数据；台式机不显示电池项。
- **一键导出诊断包**：隐私页 → 导出诊断包，日志 + 版本/系统信息 + 开关状态打成 zip，不含统计数据、连接记录、密码和 VPN 配置。
- **运行内存整理**：手动一键整理，或开启“内存高时自动整理”（默认关闭，持续 1 分钟超阈值才触发，10 分钟冷却）。只让后台程序交还暂时不用的内存，不关闭任何程序。
- **系统更新检测**：主面板 → 系统更新。显示 Windows 版本、最近补丁、是否等待重启；点“检查可用更新”调用 Windows 自带更新服务列出未安装的更新（安全更新优先，重要安全更新会通知）。只检查，不下载、不安装、不重启。
- **VPN（sing-box）**：主面板 → VPN。选择你自己的 sing-box.exe 和配置文件即可一键连接/断开，可选在连接期间设置系统代理（断开、意外退出、退出 NetPet 都会恢复原设置，上次崩溃遗留的代理也会在下次启动时恢复）。NetPet 不下载 sing-box、不拉取订阅、不内置服务器。
- **启动管理**：主面板 → 启动管理（托盘菜单也有入口），列出注册表 Run 和启动文件夹里的开机启动项，标出值得确认的项目；当前用户的启动项可一键禁用/重新启用（与任务管理器做法相同，只改启用标记，不删除任何东西）。所有用户的启动项只显示，需用任务管理器修改。
- **真实联网检测（可选，默认关闭）**：隐私页开启后每 30 秒请求 Windows 自带的联网检测地址，区分“已连接但上不了网”和“需要网页登录的 Wi-Fi”，宠物/面板显示并通知。不发送任何本机数据。

**修复：检测结果不准**
- 健康检查：监听在 0.0.0.0 / :: 上的端口（真正对外开放的）之前被漏检，现在会检查。
- 装了第三方杀毒/防火墙不再误判“实时保护已关闭”；Defender 快速扫描失败会如实提示。
- 纯 IPv6 网络不再误报断网。

**修复：数据**
- 今日流量每分钟落盘，异常退出/关机最多丢 1 分钟；流量按真实采样间隔累计（之前偏少）。
- 常驻运行时也会按保留天数清理历史数据；健康检查每 6 小时自动复查，问题解决后警示牌自动消失。
- 安全模式下修改隐私开关不再覆盖原来的设置；导出 CSV 防公式注入。

**修复：系统清理更保守**
- 不再清理 C:\Windows\Logs；临时文件只清 24 小时以前的；重复目录不再重复计算；浏览器缓存覆盖所有配置（Profile N）；回收站扫描全部盘并如实报告清理结果。

**修复：稳定性与体验**
- 面板密码锁改为主进程强制校验，关闭主面板即重新上锁（仍是防误操作，不是加密）。
- 宠物窗口 5 分钟内最多自动重建 3 次；重建后保持鼠标穿透；一键复位 30 秒后恢复全屏隐藏规则。
- 面板密码、sing-box 路径、VPN 代理备份改为用 Windows 账户加密（safeStorage / DPAPI）保存，旧版明文自动迁移。
- 安全模式启动时会提示；日志运行中也会轮换（最多保留 5 个）；进程排行/电池信息加缓存，降低开销。

## 3D 小宠物（v1.1）

切换方式：右键小宠物/托盘图标 → 切换宠物；或 面板 → 设置 → 选择小宠物。
所有造型都是代码用基础几何体搭出来的，不需要模型文件，也不联网。如果显卡不支持 WebGL，会自动退回 2D 小猫。

### 改造型 / 加新宠物（可选）
1. `src/shared/petlist.ts` 加一行；`src/renderer/pets3d.ts` 的 `SPEC` 里加一份造型参数
2. 运行 `npm run build`（3D 宠物代码会一起打包）
