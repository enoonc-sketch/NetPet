# NetPet V0.2

会显示网速的桌面小宠物（Windows）。这是按修订规范 V1.1 做的 V0.2 版：V0.1 的全部功能 + 宠物形象可选（2D 扁平 / 3D 毛绒）。

## V0.2 新增：宠物形象可选

- 面板 → 设置 → 宠物形象：点“2D 扁平”用原来的 SVG，点“3D 毛绒”用 `assets/pets/3d-*.png`（睡觉/发呆/开心/狂蹦 4 张，随网速状态自动换）
- 3D 图在宠物窗口里按圆形裁切显示
- 默认仍是 2D，可随时切换，切换后立刻生效并保存

## V0.1 包含什么

- 宠物窗口：约 170×160（含头顶气泡），无边框、透明、可拖动、置顶；点一下打开面板，双击逻辑为单击打开（拖动小于 4px 视为点击），右键出菜单
- 实时网速：每秒刷新，上传 / 下载合计，自动换算 B/s、KB/s、MB/s
- 宠物心情只看网速：没流量打瞌睡、轻载发呆、中速开心、高速蹦跳
- 今日 / 本月流量统计（只存网卡合计）
- 系统托盘：显示 / 隐藏宠物、打开面板、暂停监控 / 恢复监控、勿扰模式、开机自启、始终置顶、设置、退出
- 开机自启：默认关，用户在托盘或设置里勾选才开
- 勿扰模式：开启后不弹断网 / 恢复通知

## V0.1 不包含什么

- 不结束任何进程（想结束程序请点面板里的“打开任务管理器”，自己在里面操作）
- 不记录哪个程序联网、不记录连了哪个 IP / 网站、不做反向解析
- 不做系统体检、不做 Defender 扫描、不给安全评分
- 不读通信内容、不抓包、不解密、不装驱动

## 运行

```
npm install
npm start
```

## 打包成安装程序（需在 Windows 上跑）

```
npm run dist
```

产物在 `dist/`。开机自启请用安装版开启（开发模式下自启会指向 electron.exe）。

## 数据位置

`%APPDATA%\netpet\`：设置 `settings.json`，流量 `data\traffic.json`。全部在本机，不联网上传。面板“清空流量统计”可删，或直接删掉这个目录。

## 技术

Electron + `systeminformation`（只用 `networkStats` 读网卡计数器）。渲染进程无 Node 直接访问，`contextIsolation:true`，`nodeIntegration:false`，CSP 无 `unsafe-inline`，IPC 只放白名单通道。

详见 `NetPet-规范-V1.1-修订版.md` 与 `TEST-REPORT-V0.1.md`。
