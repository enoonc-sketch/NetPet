# NetPet 1.3.3 发布前手动测试清单（Windows）

> 本版所有改动未经编译和实机运行。请按顺序执行，每项打 ✅ / ❌ 并在“备注”记录现象。
> 建议环境：Windows 10 22H2 与 Windows 11 各一台；至少一台笔记本；一台装有第三方杀毒（如火绒）。
> 每完成一大节，执行一次 **隐私 → 导出诊断包**，留作记录。

## 0. 构建与自动测试
- [ ] `npm install` 成功
- [ ] `npm run typecheck` 无报错（重点：main.ts、vpn.ts、startup.ts、winupdate.ts、secure.ts、memtrim.ts、extras.ts）
- [ ] `npm test` 最后一行输出 `all tests ok`
- [ ] `build.bat` 生成安装包；安装、启动、托盘图标出现
- [ ] 覆盖安装到 1.3.2 之上：原设置、宠物、统计数据都保留

## 1. 升级与加密（secure）
- [ ] 1.3.2 设过面板密码 → 升级后密码仍然有效
- [ ] 用 SQLite 工具打开 `netpet.db` → `settings` 表里 `lock`、`vpn` 是 `{"$enc":1,"d":"..."}` 格式
- [ ] 隐私页“敏感设置加密”显示“已加密”
- [ ] 把 `%APPDATA%\NetPet` 拷到另一个 Windows 账户启动 → 弹“面板密码已失效”通知，密码移除，其他设置保留，不崩溃
- [ ] 日志里有“已把旧版明文敏感设置改为加密保存”

## 2. 密码锁（主进程强制）
- [ ] 设密码 → 关闭主面板 → 再打开需要输密码
- [ ] 未解锁时，开发者工具里调用 `netpet.invoke('clear-all')` 被拒绝（报 locked）
- [ ] 小面板不受影响；解锁后所有页面功能正常
- [ ] 移除密码后不再提示

## 3. 安全模式
- [ ] 启动中途强制结束进程 → 再次启动自动进入安全模式，并弹通知、打开主面板
- [ ] 安全模式下改隐私开关 → 退出安全模式 → 隐私开关恢复为原来的选择
- [ ] 安全模式下 VPN “连接”不可用，自动内存整理、联网检测被关闭

## 4. 网速、流量与额度
- [ ] 下载一个大文件，今日流量增长与实际文件大小大致一致（误差 < 10%）
- [ ] 任务管理器结束 NetPet 进程 → 重启后今日流量只少约 1 分钟
- [ ] 开启 VPN（TUN）时网速不翻倍
- [ ] 设置额度为略高于本月已用量的值 → 达到 80% 时收到通知、气泡显示“流量快用完了”；概览页进度条正确
- [ ] 同一档不重复提醒；改额度后重新计算

## 5. 联网检测（probe）
- [ ] 隐私页开启 → 正常网络下无提示
- [ ] 拔网线但保留 Wi-Fi 适配器连接到无外网的路由器 → 约 1 分钟内显示“已连接但上不了网”
- [ ] 连需要网页登录的 Wi-Fi → 显示“需要网页登录”；登录后自动消失
- [ ] 纯 IPv6 网络（如有条件）不再显示“网络已断开”

## 6. 系统健康
- [ ] 体检可完成，无“未捕获异常”日志
- [ ] 开启远程桌面或文件共享 → “本机监听端口”出现 3389 / 445 提醒
- [ ] 装第三方杀毒的电脑 → 病毒防护显示“由第三方杀毒软件提供保护”，不扣分
- [ ] 硬盘健康项显示每块硬盘状态；USB 硬盘读不到时显示“无法检测”而非报错
- [ ] 笔记本显示电池损耗百分比，台式机没有电池项
- [ ] Defender 快速扫描（非管理员）失败时提示“没有成功完成”
- [ ] 6 小时后自动复查（可临时把间隔改小验证）

## 7. 系统更新检测
- [ ] 打开页面自动显示本机状态：版本号、最近补丁、是否待重启
- [ ] 点“检查可用更新” 1～3 分钟内出结果；有更新时列表、KB、大小正确
- [ ] 禁用 wuauserv 服务后检查 → 显示“在线检查失败”提示，不卡死
- [ ] “打开 Windows 更新”打开系统设置页

## 8. 启动管理
- [ ] 列表与任务管理器“启动应用”基本一致
- [ ] 禁用一个当前用户启动项 → 任务管理器里同一项显示“已禁用”；重启后确实不启动
- [ ] 在 NetPet 里重新启用 → 任务管理器同步显示“已启用”
- [ ] “所有用户”项显示“需管理员”、不能切换；“位置”按钮能定位文件
- [ ] 名称含空格、中文、引号的启动项也能正确禁用/启用

## 9. VPN（sing-box）
- [ ] 选择非 sing-box 的 exe 被拒绝
- [ ] 配置有语法错误 → 提示“配置检查没通过”，日志显示原因，不启动
- [ ] 正常配置（mixed 入站）连接 → 系统代理变为 127.0.0.1:端口，浏览器可访问
- [ ] 断开 → 系统代理恢复为连接前的设置（事先设置一个自定义代理来验证是“恢复原值”而不是“清空”）
- [ ] 连接中用任务管理器结束 sing-box → 状态变“出错”，系统代理已恢复，弹通知
- [ ] 连接中结束 NetPet 进程 → 下次启动 NetPet 时系统代理被恢复
- [ ] TUN 配置非管理员运行 → 提示需要管理员；管理员运行可正常连接
- [ ] 连接 / 断开后体检不误报“系统代理被修改”
- [ ] 退出 NetPet 时 sing-box 进程不残留

## 10. 运行内存整理
- [ ] 手动整理：提示处理程序数和可用内存增加量；没有任何程序被关闭
- [ ] 前台窗口（如正在编辑的 Word）不被整理
- [ ] 开启自动整理、阈值 80%，制造高内存占用（打开大量浏览器标签）→ 持续约 1 分钟后自动整理并通知；10 分钟内不重复

## 11. 系统清理
- [ ] 扫描结果中“用户临时文件”不再是两倍大小
- [ ] 新建一个临时文件（24 小时内）→ 清理后仍存在
- [ ] 不出现 `C:\Windows\Logs`；以管理员运行清理后 `C:\Windows\Logs\CBS` 仍完整
- [ ] 回收站：多个盘都有文件 → 扫描大小包含所有盘；清空后释放大小正确；有文件被占用时如实提示
- [ ] Chrome/Edge 有多个配置时，各配置缓存都被计入
