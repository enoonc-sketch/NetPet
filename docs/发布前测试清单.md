# NetPet 1.5.0 发布前手动测试清单（Windows）

> 1.5.0：**第 18 节为本版新增的 11 个功能 + 内存整理改进，请优先执行**；第 2、4、7、12 节涉及的代码本版也有改动。
> 1.4.0：第 0 节新增 CI / 便携版检查，第 17 节为 1.4.0 新功能和修复；1~16 节沿用 1.3.3，其中第 2、9、12 节涉及的代码本版有改动，建议全部重测。

> 本版所有改动未经编译和实机运行。请按顺序执行，每项打 ✅ / ❌ 并在“备注”记录现象。
> 建议环境：Windows 10 22H2 与 Windows 11 各一台；至少一台笔记本；一台装有第三方杀毒（如火绒）。
> 每完成一大节，执行一次 **隐私 → 导出诊断包**，留作记录。
