# NetPet 使用说明

## 安装与运行
- 安装版：运行 `build.bat` 打包后，在 `dist` 里双击安装程序（默认装到当前用户，不需要管理员权限，会创建桌面快捷方式）。
- 开发运行：`npm install` → `npm start`（需要 Node.js）；`npm test` 跑单元测试；`npm run typecheck` 做类型检查。
- 卸载：开始菜单或“设置 → 应用”卸载。卸载时会询问是否一并删除本地数据；选“否”则保留，重装后可继续使用。

## 日常使用
- **宠物**：按住拖动（拖不出屏幕，至少留 40px 在屏幕内）；**单击**展开小面板；**双击**打开完整窗口；右键弹出菜单。
- **小宠物不见了？一键复位**：右键小宠物 / 右键托盘图标 → **一键复位小宠物**，或完整窗口 → 设置 → 一键复位小宠物（小面板里也有“复位小宠物”按钮）。复位只做四件事：位置回主显示器右下角、恢复显示、取消鼠标穿透、恢复置顶；不动宠物种类、隐私开关、监控数据和成长经验。
- **紧凑模式**（托盘菜单或 设置 页）：宠物窗口缩小到约 96×100，速度改成一行小字，更不占地方。
- **托盘**：单击托盘图标——宠物已隐藏时恢复显示，正常时弹出菜单（单击不再直接隐藏，避免误点让宠物“消失”）；双击 打开主面板；右键菜单有 一键复位、暂停监控、勿扰模式、鼠标穿透、切换宠物、设置、开机自启、清理系统垃圾、退出。
- **系统垃圾清理**：完整窗口 → 系统清理。先点“重新扫描”，勾选要清的类别，再确认才删除。包括用户临时文件、Windows 临时文件、浏览器缓存、崩溃转储与日志、回收站、NetPet 旧日志（只清 30 天前的）。只删白名单里的目录，正在使用的文件自动跳过；绝不碰文档、下载、桌面、图片和程序文件，也不清理 Windows Update 下载和 Prefetch。回收站清空后不可恢复，默认不勾选。
- **宠物状态**：待机、开心、睡觉（网络空闲 60 秒）、累了（CPU 高负载 30 秒）、发热（温度 ≥85℃，传感器支持时）、内存紧张（出汗）、下载中、上传中、有提醒（系统健康检查出现“异常”）。状态切换有持续时间要求和最短停留时间，不会来回抖动。
- **勿扰模式**：不弹通知，也不显示状态类动画；**暂停监控**：停止所有采集。

## 隐私（完整窗口 → 隐私）
每项监控都能单独开关，页面里写明：监控什么、为什么、数据存放、是否要管理员权限、如何停止、如何删除。隐私页顶部有一张“联网与系统修改一览”。
- **默认开启**：网速、硬件状态（只读本机，不联网）。其余全部默认关闭。
- **会联网的只有 5 项**：解析主机名（反向 DNS）、真实联网检测、系统更新的在线检查、检查 NetPet 新版本、VPN。前两项是隐私页开关，默认关；后三项只在你点击时运行。
- **会修改系统的只有**：开机自启、系统清理、启动管理、VPN 连接期间的系统代理，都要你主动操作。
- NetPet 不会：上传或同步任何数据、读取通信内容、记录键盘/屏幕/浏览器历史/用户文件、自动结束程序、安装更新或重启电脑。（运行内存整理只让程序交还暂时不用的内存，不关闭程序。）
- 完整说明（每项连到哪里、对方能看到什么、本机存了什么）见 `隐私数据流审查.md`。

## 数据
数据目录：`%APPDATA%\NetPet\`（含 `data\netpet.db`）。可在隐私页 打开文件夹、备份数据库、清空全部历史数据；保留天数在设置里调整。

## 已知限制（如实说明）
- **按程序统计的流量未实现**（需要 ETW + 原生组件/管理员权限）。“连接记录”只是元数据，不含流量大小。
- GPU 占用率、温度取决于硬件和驱动是否提供，读不到时显示“无法检测/读不到”，不会编造。
- “全屏时自动隐藏”使用 Windows 自带接口，**尚未在真实 Windows 上测试**。
- 系统健康检查的 Defender/防火墙/更新/代理项依赖 PowerShell 命令，**尚未在真实 Windows 上测试**。
- VPN 的启动/停止和系统代理设置与恢复**尚未在真实 Windows 上测试**。
- 启动管理的读写（StartupApproved 标记）**尚未在真实 Windows 上测试**；不包含计划任务和服务方式的自启。

## 启动卡住怎么办
见 `排障说明.md`：用“NetPet-安全模式.bat”启动，并把 `%APPDATA%\NetPet\logs\netpet.log` 发给我。


## 启动管理（1.3.3 新增）
主面板 → **启动管理**（或右键托盘图标 → 启动管理…）。
- 列出开机自动运行的程序：注册表 Run（当前用户 / 所有用户）和启动文件夹。标 ⚠ 的项目值得确认一下，但不代表有问题。
- **禁用 / 启用**：只对“当前用户”的启动项开放。和任务管理器“启动应用”的做法一样，只改启用标记，不删除文件或注册表项，下次开机生效，随时可以恢复。
- **所有用户**的启动项需要管理员权限，这里只显示，可点“打开任务管理器 · 启动应用”修改。
- “位置”按钮会在资源管理器里定位这个程序文件。
- 只在打开这一页时读取，不保存、不上传；设置了面板密码时同样受保护。

## VPN（sing-box，1.3.3 新增）
主面板 → **VPN**（或右键托盘图标 → VPN）。
1. 自己准备 sing-box（从 sing-box 官方 GitHub 发布页下载 Windows 版，解压出 `sing-box.exe`）和一份配置文件（.json）。
2. 在 VPN 页分别点“选择…”选好程序和配置，点 **连接**。NetPet 会先运行 `sing-box check` 检查配置，没问题才启动。
3. **系统代理**（默认开启）：配置里需要有监听本机的 `mixed` 或 `http` 入站，例如
   `{"type":"mixed","listen":"127.0.0.1","listen_port":2080}`。连接后系统代理指向 `127.0.0.1:端口`，局域网地址不走代理。
4. **TUN 模式**：配置里有 `tun` 入站时，需要右键 NetPet →“以管理员身份运行”，此时可以关闭“设置系统代理”。
5. 断开、sing-box 意外退出、退出 NetPet 时都会恢复你原来的代理设置；如果 NetPet 崩溃，下次启动会自动恢复。
- sing-box 的日志只在内存里保留最近几百行，不写入文件。
- NetPet 不下载 sing-box、不拉取订阅、不内置任何服务器。请遵守当地法律法规。

## 系统更新（1.3.3 新增）
主面板 → **系统更新**（或右键托盘图标 → 检查系统更新…）。
- **只看本机状态**（不联网，打开页面时自动执行一次）：Windows 版本号、最近一次补丁、是否有更新等待重启。
- **检查可用更新**（联网）：调用 Windows 自带的更新服务，和“设置 → Windows 更新 → 检查更新”是同一个通道，由 Windows 自己联系微软服务器，可能要 1～3 分钟。列出未安装的更新，安全更新排在前面；有 Critical/Important 级别的安全更新时会通知一次。
- NetPet **不会下载、安装更新或重启电脑**。点“打开 Windows 更新”自己安装。

## 运行内存整理（1.3.3 新增）
- **手动**：主面板 → 概览 → 资源占用排行 →“整理运行内存”，或右键托盘图标 → 整理运行内存。
- **自动**（默认关闭）：设置页开启“运行内存高时自动整理”，选阈值（80/85/90/95%）。内存占用持续 1 分钟超过阈值才整理，两次之间至少隔 10 分钟，整理后会通知一次。
- 原理：调用 Windows 的 EmptyWorkingSet，让后台程序把暂时不用的内存页交还给系统（与常见“内存整理”工具相同）。**不关闭任何程序**；跳过系统关键进程、资源管理器、杀毒软件、NetPet 自己、sing-box 和你当前正在用的窗口。
- 如实说明：效果因电脑而异。被整理的程序再次用到这部分内存时会从内存压缩区或页面文件取回，可能短暂变慢；内存长期不够用时，根本办法是关掉不用的程序或加内存。不清理系统“备用列表”（需要管理员权限，且会让之后打开程序变慢）。

## 流量额度、提醒与诊断（1.3.3 新增）
- **流量额度**：设置页填“每月流量额度（GB）”，0 表示不提醒。按自然月统计网卡总流量（上传+下载），到 80% 和 100% 各提醒一次，每月 1 日重新计算；概览页“网卡总流量”下显示进度条。需要“网络速度监控”开启。
- **新程序首次联网提醒**：隐私页开关，默认关闭，需要同时开启“网络使用统计（连接记录）”。开启后前 24 小时只学习你现有的程序，之后第一次连外网的程序会提醒，并记到“系统健康 → 历史提醒”。关掉再开会重新学习。
- **久坐 / 喝水提醒**：设置页选间隔（30～120 分钟）。只按你实际在用电脑的时间计时；离开 5 分钟以上算休息过，久坐重新计时。勿扰、全屏、暂停监控、宠物隐藏时不打扰（也不补发）。
- **硬盘 / 电池健康**：在“系统健康”体检里，读 Windows 自带的硬盘健康数据和电池容量。部分 USB/RAID 硬盘、部分电池不提供数据，会显示“无法检测”而不是乱猜。
- **导出诊断包**：隐私页 → 数据管理 → 导出诊断包。反馈问题时把这个 zip 发给开发者即可。包含日志、版本、系统信息（显示器、显卡状态）、开关状态、最近体检结论；**不包含**流量统计、连接记录、密码、VPN 程序/配置的路径和内容。保存前后都可以自己打开检查。

## 检查 NetPet 新版本（1.3.3 新增）
设置页 → 关于 →“检查新版本”（或右键托盘图标 → 检查 NetPet 新版本…）。点击后访问一次 GitHub 上 NetPet 的发布页接口，显示是否有新版本和更新内容；有新版本时点“打开发布页下载”，在浏览器里自己下载安装包。NetPet 不会自动检查、下载或安装，预发布版不提示。
