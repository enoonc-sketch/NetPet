# NetPet 使用说明（v1.5.0）

## 安装与运行
- 安装版：运行 `build.bat` 打包后，在 `dist` 里双击安装程序（默认装到当前用户，不需要管理员权限，会创建桌面快捷方式）。
- 便携版：运行 `npm run dist:all`（或 `npm run portable`）后，`dist` 里的 `NetPet-1.5.0-portable.exe` 双击即可运行，不需要安装。
- 开发运行：`npm install` → `npm start`（需要 Node.js 22.13 及以上）；`npm test` 跑单元测试；`npm run typecheck` 做类型检查；`npm run check` 两项一起跑。
- 卸载：开始菜单或“设置 → 应用”卸载。卸载时会询问是否一并删除本地数据；选“否”则保留，重装后可继续使用。

## 日常使用
- **宠物**：按住拖动（拖不出屏幕，至少留 40px 在屏幕内）；**单击**展开小面板；**双击**打开完整窗口；右键弹出菜单。
- **快捷键显示 / 隐藏宠物**（1.4.0）：默认 `Ctrl+Alt+P`，在任何程序里按下都能切换。详见下文“快捷键”。
- **首次使用**：第一次打开完整窗口时，顶部有一张欢迎卡片，介绍基本操作和隐私默认值；点“我已了解，开始使用”后不再显示。
- **深色模式**（1.4.0）：界面自动跟随 Windows“设置 → 个性化 → 颜色 → 选择模式”，无需单独设置。
- **小宠物不见了？一键复位**：右键小宠物 / 右键托盘图标 → **一键复位小宠物**，或完整窗口 → 设置 → 一键复位小宠物（小面板里也有“复位小宠物”按钮）。复位只做四件事：位置回主显示器右下角、恢复显示、取消鼠标穿透、恢复置顶；不动宠物种类、隐私开关、监控数据和成长经验。
- **紧凑模式**（托盘菜单或 设置 页）：宠物窗口缩小到约 96×100，速度改成一行小字，更不占地方。
- **托盘**：单击托盘图标——宠物已隐藏时恢复显示，正常时弹出菜单（单击不再直接隐藏，避免误点让宠物“消失”）；双击 打开主面板；右键菜单有 一键复位、暂停监控、勿扰模式、鼠标穿透、切换宠物、设置、开机自启、清理系统垃圾、退出。
- **系统垃圾清理**：完整窗口 → 系统清理。先点“重新扫描”，勾选要清的类别，再确认才删除。包括用户临时文件、Windows 临时文件、浏览器缓存、崩溃转储与日志、回收站、NetPet 旧日志（只清 30 天前的）。只删白名单里的目录，正在使用的文件自动跳过；绝不碰文档、下载、桌面、图片和程序文件，也不清理 Windows Update 下载和 Prefetch。回收站清空后不可恢复，默认不勾选。
- **宠物状态**：待机、开心、睡觉（网络空闲 60 秒）、累了（CPU 高负载 30 秒）、发热（温度 ≥85℃，传感器支持时）、内存紧张（出汗）、下载中、上传中、有提醒（系统健康检查出现“异常”）。状态切换有持续时间要求和最短停留时间，不会来回抖动。
- **勿扰模式**：不弹通知，也不显示状态类动画；**暂停监控**：停止所有采集。

## 隐私（完整窗口 → 隐私）
每项监控都能单独开关，页面里写明：监控什么、为什么、数据存放、是否要管理员权限、如何停止、如何删除。隐私页顶部有一张“联网与系统修改一览”。
- **默认开启**：网速、硬件状态（只读本机，不联网）。其余全部默认关闭。
- **会联网的只有 5 项**：解析主机名（反向 DNS）、真实联网检测、系统更新的在线检查、检查 NetPet 新版本、VPN。前两项是隐私页开关，默认关；后三项只在你点击时运行。
- **会修改系统的只有**：开机自启、系统清理、启动管理、VPN 连接期间的系统代理，都要你主动操作。
- NetPet 不会：上传或同步任何数据、读取通信内容、记录键盘/屏幕/浏览器历史/用户文件、自动结束程序、安装更新或重启电脑。（运行内存整理只让程序交还暂时不用的内存，不关闭程序。）
- 完整说明（每项连到哪里、对方能看到什么、本机存了什么）见 `隐私数据流审查.md`。
- 1.4.0 新增的快捷键、设置导出 / 导入、流量周报都**不联网**，也不修改系统设置。

## 数据
数据目录：`%APPDATA%\NetPet\`（含 `data\netpet.db`）。可在隐私页 打开文件夹、备份数据库、清空全部历史数据；保留天数在设置里调整。

## 已知限制（如实说明）
- **按程序统计的流量未实现**（需要 ETW + 原生组件/管理员权限）。“连接记录”只是元数据，不含流量大小。
- GPU 占用率、温度取决于硬件和驱动是否提供，读不到时显示“无法检测/读不到”，不会编造。
- “全屏时自动隐藏”使用 Windows 自带接口，**尚未在真实 Windows 上测试**。
- 系统健康检查的 Defender/防火墙/更新/代理项依赖 PowerShell 命令，**尚未在真实 Windows 上测试**。
- VPN 的启动/停止和系统代理设置与恢复**尚未在真实 Windows 上测试**（1.4.0 修复了几处启动/断开竞态，同样未实测）。
- 启动管理的读写（StartupApproved 标记）**尚未在真实 Windows 上测试**；不包含计划任务和服务方式的自启。
- **1.4.0 全部改动未经编译和实机运行**（开发环境没有 Windows / Node.js）。发布前必须在 Windows 上跑 `npm run typecheck`、`npm test`、`build.bat`，并按 `发布前测试清单.md` 第 17 节验证新功能。
- 全局快捷键只能从固定的几个组合里选；如果被其他程序（输入法、截图工具等）占用，Windows 不允许 NetPet 注册，需要换一个。
- 流量周报只统计整台电脑的网卡总流量，不区分程序；“保留天数”不影响按天流量（按天流量保留约 400 天）。
- 设置导入只恢复偏好设置，不恢复统计数据；想整体迁移数据请用“隐私 → 备份数据库”。
- 深色模式只跟随系统，暂不提供手动切换；宠物 3D 造型颜色不随主题变化。

## 启动卡住怎么办
见 `排障说明.md`：用“NetPet-安全模式.bat”启动，并把 `%APPDATA%\NetPet\logs\netpet.log` 发给我。


## 启动管理（1.3.3 新增）
主面板 → **启动管理**（或右键托盘图标 → 启动管理…）。
- 列出开机自动运行的程序：注册表 Run（当前用户 / 所有用户）和启动文件夹。标 ⚠ 的项目值得确认一下，但不代表有问题。
- **禁用 / 启用**：只对“当前用户”的启动项开放。和任务管理器“启动应用”的做法一样，只改启用标记，不删除文件或注册表项，下次开机生效，随时可以恢复。
- **所有用户**的启动项需要管理员权限，这里只显示，可点“打开任务管理器 · 启动应用”修改。
- “位置”按钮会在资源管理器里定位这个程序文件。
- 只在打开这一页时读取，不保存、不上传；设置了面板密码时同样受保护。

## VPN（sing-box，1.3.3 新增）
主面板 → **VPN**（或右键托盘图标 → VPN）。
1. 自己准备 sing-box（从 sing-box 官方 GitHub 发布页下载 Windows 版，解压出 `sing-box.exe`）和一份配置文件（.json）。
2. 在 VPN 页分别点“选择…”选好程序和配置，点 **连接**。NetPet 会先运行 `sing-box check` 检查配置，没问题才启动。
3. **系统代理**（默认开启）：配置里需要有监听本机的 `mixed` 或 `http` 入站，例如
   `{"type":"mixed","listen":"127.0.0.1","listen_port":2080}`。连接后系统代理指向 `127.0.0.1:端口`，局域网地址不走代理。
4. **TUN 模式**：配置里有 `tun` 入站时，需要右键 NetPet →“以管理员身份运行”，此时可以关闭“设置系统代理”。
5. 断开、sing-box 意外退出、退出 NetPet 时都会恢复你原来的代理设置；如果 NetPet 崩溃，下次启动会自动恢复。
- sing-box 的日志只在内存里保留最近几百行，不写入文件。
- NetPet 不下载 sing-box、不拉取订阅、不内置任何服务器。请遵守当地法律法规。

## 系统更新（1.3.3 新增）
主面板 → **系统更新**（或右键托盘图标 → 检查系统更新…）。
- **只看本机状态**（不联网，打开页面时自动执行一次）：Windows 版本号、最近一次补丁、是否有更新等待重启。
- **检查可用更新**（联网）：调用 Windows 自带的更新服务，和“设置 → Windows 更新 → 检查更新”是同一个通道，由 Windows 自己联系微软服务器，可能要 1～3 分钟。列出未安装的更新，安全更新排在前面；有 Critical/Important 级别的安全更新时会通知一次。
- NetPet **不会下载、安装更新或重启电脑**。点“打开 Windows 更新”自己安装。

## 运行内存整理（1.3.3 新增）
- **手动**：主面板 → 概览 → 资源占用排行 →“整理运行内存”，或右键托盘图标 → 整理运行内存。
- **自动**（默认关闭）：设置页开启“运行内存高时自动整理”，选阈值（80/85/90/95%）。内存占用持续 1 分钟超过阈值才整理，两次之间至少隔 10 分钟，整理后会通知一次。
- 原理：调用 Windows 的 EmptyWorkingSet，让后台程序把暂时不用的内存页交还给系统（与常见“内存整理”工具相同）。**不关闭任何程序**；跳过系统关键进程、资源管理器、杀毒软件、NetPet 自己、sing-box 和你当前正在用的窗口。
- 如实说明：效果因电脑而异。被整理的程序再次用到这部分内存时会从内存压缩区或页面文件取回，可能短暂变慢；内存长期不够用时，根本办法是关掉不用的程序或加内存。不清理系统“备用列表”（需要管理员权限，且会让之后打开程序变慢）。

## 流量额度、提醒与诊断（1.3.3 新增）
- **流量额度**：设置页填“每月流量额度（GB）”，0 表示不提醒。按自然月统计网卡总流量（上传+下载），到 80% 和 100% 各提醒一次，每月 1 日重新计算；概览页“网卡总流量”下显示进度条。需要“网络速度监控”开启。
- **新程序首次联网提醒**：隐私页开关，默认关闭，需要同时开启“网络使用统计（连接记录）”。开启后前 24 小时只学习你现有的程序，之后第一次连外网的程序会提醒，并记到“系统健康 → 历史提醒”。关掉再开会重新学习。
- **久坐 / 喝水提醒**：设置页选间隔（30～120 分钟）。只按你实际在用电脑的时间计时；离开 5 分钟以上算休息过，久坐重新计时。勿扰、全屏、暂停监控、宠物隐藏时不打扰（也不补发）。
- **硬盘 / 电池健康**：在“系统健康”体检里，读 Windows 自带的硬盘健康数据和电池容量。部分 USB/RAID 硬盘、部分电池不提供数据，会显示“无法检测”而不是乱猜。
- **导出诊断包**：隐私页 → 数据管理 → 导出诊断包。反馈问题时把这个 zip 发给开发者即可。包含日志、版本、系统信息（显示器、显卡状态）、开关状态、最近体检结论；**不包含**流量统计、连接记录、密码、VPN 程序/配置的路径和内容。保存前后都可以自己打开检查。

## 检查 NetPet 新版本（1.3.3 新增）
设置页 → 关于 →“检查新版本”（或右键托盘图标 → 检查 NetPet 新版本…）。点击后访问一次 GitHub 上 NetPet 的发布页接口，显示是否有新版本和更新内容；有新版本时点“打开发布页下载”，在浏览器里自己下载安装包。NetPet 不会自动检查、下载或安装，预发布版不提示。

## 快捷键（1.4.0 新增）
- 默认 `Ctrl+Alt+P`：宠物正在显示 → 隐藏；宠物没显示（手动隐藏、或被“全屏时自动隐藏”藏起来）→ 显示。全屏时按下会先显示 30 秒，之后全屏隐藏规则恢复。
- 设置页 →“显示 / 隐藏宠物的快捷键”可以换成 `Ctrl+Alt+N`、`Ctrl+Alt+H`、`Ctrl+Shift+P`、`Alt+Shift+P`，或选“关闭”。
- 如果组合键已被其他程序占用，设置页会显示“⚠ 已被其他程序占用，请换一个”，日志里也会记一条。
- 托盘菜单里“显示宠物 / 隐藏宠物”后面会标出当前快捷键，方便记住。

## 设置导出 / 导入（1.4.0 新增）
设置页 →“导出 / 导入设置”。
- **导出**：选一个位置保存 `netpet-settings-日期.json`。包含：紧凑模式、置顶、宠物种类、保留天数、内存提醒阈值、隐私开关、动画开关、运行内存自动整理、流量额度、久坐 / 喝水提醒、新程序首次联网提醒开关、快捷键。
- **不包含**：面板密码、sing-box 程序 / 配置路径、VPN 代理备份、窗口位置、成长经验、体检基线、任何统计数据和历史记录。
- **导入**：选择之前导出的文件。只认 NetPet 导出的格式，文件里的每一项都会重新校验，不认识或不合法的值直接忽略。**开机自启不会被导入**（会修改系统，请在本机自己开启）。如果导入会把某些监控从“关”变成“开”（例如连接记录、真实联网检测），会先弹窗列出，确认后才导入。
- 安全模式下导入的隐私开关只对本次运行生效，退出安全模式后恢复原来的选择。

## 流量周报 / 月报（1.4.0 新增）
完整窗口 → 网络统计 →“流量周报 / 月报”。
- 切换“7 天 / 30 天”，按天显示下载（绿）和上传（紫）柱状图，下面给出合计下载、合计上传、日均和用得最多的一天。
- 数据来自本机数据库里按天累计的网卡总流量，和“今天 / 本月”是同一口径（整台电脑，含局域网传输），不区分程序。
- 需要“网络速度监控”开启；关闭期间没有数据的日子显示为 0。


## 1.5.0 新功能

### 语言 / Language
设置页最上方 → 语言：**跟随系统**（默认；Windows 显示语言是中文时用中文，否则用英文）/ 中文 / English；托盘菜单 → 语言 也可以切换。主面板、小面板、宠物气泡、托盘菜单、通知和对话框会立即一起切换。少数由系统检查生成的明细文字（健康检查的检查依据、系统清理的类别说明、启动项来源等）目前只有中文。

### 网速异常提醒（默认关闭）
设置页 → 网速异常提醒。两种情况会提醒（宠物气泡 + 通知，一种情况一次）：
- **下载卡住 / 很慢**：先有一段真正的下载（速度 ≥ 约 4 倍“卡住阈值”且至少 256 KB/s，持续 5 秒），之后速度连续 N 秒低于设定值（默认 50 KB/s、60 秒）。下载结束后速度降到几乎为 0 不算卡住，不会提醒。
- **持续高速**：下载速度连续 N 秒高于设定值（默认关闭；可选 5～100 MB/s）。回落到设定值的 80% 以下才会重新计时。
- 同一类提醒之间有冷却时间（默认 10 分钟）；勿扰、全屏、暂停监控时不提醒，解除后也不会补发。只使用本机网速数据，需要“网络速度监控”开启。

### 番茄钟
主面板 → 番茄钟（概览页也有一张小卡片），或小面板底部、托盘菜单 → 番茄钟。
- 默认专注 25 分钟 → 休息 5 分钟，可在番茄钟页调整（专注 15～60 分钟、休息 3～15 分钟，从下一轮生效）。
- 可以开始 / 暂停 / 继续 / 跳过当前阶段 / 重置；计时按“结束时刻”计算，电脑休眠唤醒后不会走偏。
- 专注期间宠物气泡显示“🍅 专注中 · 剩 N 分钟”，**久坐提醒暂停**（喝水提醒照常）。专注结束和休息结束各发一条通知（勿扰、全屏、暂停监控时只在宠物气泡里提示）。
- 每天完成的个数和分钟数保存在本机（`daily_counters` 表，保留 400 天），番茄钟页显示最近 14 天。番茄钟不受“暂停监控”影响。

### 硬件历史曲线
概览页 → 硬件历史曲线：CPU %、内存 %、CPU 温度（读得到时；与百分比共用 0～100 刻度）。可切换 24 小时（每分钟一个点）/ 7 天（每 30 分钟取平均，并显示区间 CPU 峰值）。NetPet 没运行的时间段曲线会断开。数据来自已有的 `hardware_statistics` 表（每分钟一条），保留天数跟随设置页“历史数据保留天数”；需要“硬件状态监控”开启。

### 每周使用小结（默认开启）
每周一（本地时间）第一次使用电脑时，NetPet 在本机汇总上一周（周一 0 点 ~ 周日 24 点）：流量合计与日均、用得最多的一天、健康检查次数与分数、提醒次数（久坐 / 喝水 / 网速异常）、番茄钟个数与分钟、CPU 峰值，并发一条通知（勿扰 / 全屏 / 暂停时不发；一周几乎没有数据时也不发）。周一没开机，会在本周第一次使用时补上。主面板 → 每周小结 可以查看历史（最多 60 份）、立即重新生成、或关闭此功能。完全在本机生成，不联网。
> 注意：硬件和健康检查数据按“历史数据保留天数”清理，设为 7 天时上周最早一两天的这部分数据可能已经被清理；流量和番茄钟按天保留 400 天，不受影响。

### 宠物换装和配色
宠物页 → 换装和配色：8 种配色（原色、薄荷、天空、薰衣草、樱花、午夜、可可、金色）和 6 种配饰（礼帽、围巾、眼镜、蝴蝶结、小花、王冠）。按成长等级或成就解锁（未解锁的显示 🔒 和解锁条件），左侧有 3D 预览。只改变 3D 宠物的外观；3D 不可用（安全模式、显卡问题）时显示的 emoji 宠物不变。

### 驱动更新
主面板 → 驱动更新（托盘菜单也有入口；受面板密码锁保护）。
- 打开页面自动读取本机驱动（不联网）：设备、类别、提供商、版本、日期、是否签名；“有问题的设备”列出设备管理器里报告错误的设备，并用中文解释常见错误码（如 28 = 没有安装驱动、43 = 设备报告问题已停止、22 = 被禁用）。
- “未签名”“超过 5 年”只是提示：很多设备多年都不需要新驱动。微软系统自带驱动的日期固定为 2006-06-21，不算旧。
- “在线检查可用驱动”**点击才运行**，调用 Windows 自带的更新服务搜索可用驱动（和 Windows 更新 → 可选更新同一通道），列出名称、类别、厂商、版本日期、大小。
- NetPet **只检查，不下载、不安装、不卸载**。要更新请点“打开 Windows 更新 · 可选更新”或“打开设备管理器”。

### 病毒查杀（Microsoft Defender）
主面板 → 病毒查杀（托盘菜单也有入口；受面板密码锁保护）。
- 状态（不联网）：实时保护、病毒防护、病毒库版本和更新时间、上次快速 / 全盘扫描时间。检测到第三方杀毒软件在工作时会显示它的名字并说明 Defender 处于被动模式，此时扫描按钮停用，请用该软件扫描。
- 扫描：快速扫描、全盘扫描（可能 1 小时以上，会先确认）、自定义扫描（只能通过“选择文件… / 选择文件夹…”对话框选择路径）、离线扫描（**会立即重启电脑**，两次确认）。同一时间只运行一个；“停止等待”只是不再等结果，Defender 可能会在后台继续。扫描结束后如果有新的检测会通知。
- 更新病毒库：**点击才联网**，由 Defender 自己联系微软更新服务器。
- 威胁记录：名称、严重程度、状态、位置、时间。NetPet **不删除、不隔离、不放行**，请点“打开 Windows 安全中心 · 保护历史记录”处理。
- 定期快速扫描（默认关闭）：每周一次，只在空闲 ≥ 10 分钟、接通电源、没有全屏、没有番茄钟专注时进行。
- NetPet 不自带杀毒引擎，**绝不修改** Defender 的设置、排除项或实时保护。没有 Defender PowerShell 命令时会改用 `MpCmdRun.exe`。

### 任务管理器
主面板 → 任务管理器（托盘菜单也有入口；可在设置页设一个全局快捷键，默认关闭；受面板密码锁保护）。
- **进程**：只在本页打开时读取，每 2 秒刷新，窗口不可见时暂停。显示名称、PID、CPU、内存（工作集）、类型（应用 / 后台进程 / Windows 进程）、用户；可搜索、筛选、按列排序、按程序分组展开。按进程的磁盘 / 网络用量拿不到低成本数据，不显示。
- **详情**：路径（可“打开文件位置”）、命令行、父进程、启动时间、文件签名；未签名且位于 AppData / Temp / 下载等用户可写目录的程序标“值得确认”（不代表一定有问题）。
- **操作**（每次都要确认，都会写日志）：结束进程（先请它正常退出，2.5 秒后仍在运行再问你是否强制结束）、结束进程树（二次确认）、设置优先级（只有 低于正常 / 正常 / 高于正常，绝不设置“实时”）。系统关键进程（System、smss、csrss、wininit、winlogon、services、lsass、svchost、dwm 等）、杀毒软件进程（MsMpEng 等）和 NetPet 自己**不能结束**；以管理员或其他用户运行的进程会提示“拒绝访问”，可以以管理员身份运行 NetPet 后再试。
- **性能**：CPU（每个逻辑核心）、内存、网络的实时小图；磁盘见概览和磁盘整理页。**启动 / 服务**：链接到启动管理页；服务列表只读，本版不修改任何服务。
- 这是 NetPet 里**唯一**可以结束进程的功能；运行内存整理仍然绝不结束任何程序。

### 运行内存（整理改进）
主面板 → 运行内存。显示可用内存、已提交 / 提交上限、系统缓存、压缩内存（Memory Compression 进程的占用），以及占用最多的 10 个程序（需要“进程资源排行”开启）。
- **手动整理**：概览页或本页的“整理运行内存”。
- **内存高时自动整理**（默认关闭）：持续 1 分钟超过阈值时整理一次，会发通知。
- **定期整理**（1.5.0，默认关闭）：每 30 / 60 / 120 分钟一次，只在你离开电脑 ≥ 5 分钟（或锁屏）、没有全屏 / 游戏、没有番茄钟专注、内存占用 ≥ 60% 时进行；只处理 ≥ 100 MB 的后台进程，并跳过前台程序的同名进程。静默进行，只写日志。
- 所有自动整理之间至少隔 10 分钟；30 分钟内整理过的进程跳过；每次最多 30 个、占用最大的优先，整次最多 20 秒。
- **排除列表**：最多 50 个进程名，这些程序永远不整理。
- 每次整理 5 秒后测量“可用内存”的真实变化，最近 20 次记录在本页；如果最近 3 次定期整理每次都不到 100 MB，会提示你关闭定期整理（频繁整理会增加缺页、反而可能变慢）。
- 仍然：**绝不结束任何程序**，不清理系统备用列表。

### 磁盘整理
主面板 → 磁盘整理（托盘菜单也有入口；受面板密码锁保护）。不联网。
- 分析：分区、文件系统、容量 / 可用、类型（机械硬盘 HDD / 固态硬盘 SSD / 未知）、上次优化时间（来自 Windows 应用程序日志）、Windows 自带“计划优化”任务的状态；机械硬盘可在管理员权限下读取碎片率。
- “立即优化”调用 Windows 自带的 `Optimize-Volume`：**HDD 做碎片整理，SSD 只做 TRIM（绝不对 SSD 做碎片整理），类型未知的盘跳过**。需要以管理员身份运行 NetPet（否则可点“打开‘碎片整理和优化驱动器’”用系统工具）；用电池时不运行；同一时间只优化一个分区；可以取消；只显示已用时间（Windows 不提供可靠的进度百分比）。
- NetPet 每周自动优化（默认关闭）：在 NetPet 内部判断（**不创建系统计划任务**），空闲 ≥ 10 分钟、接通电源、没有全屏、没有番茄钟专注时依次优化，完成后发一条通知；中途拔电 / 全屏 / 开始专注就停。Windows 自带的计划优化开着时一般不需要开启。

### 温度与节能
主面板 → 温度与节能（托盘菜单 → 温度与节能 子菜单可快速切换；受面板密码锁保护）。不联网。
- 显示：CPU 温度（读得到时）、风扇转速（Windows 一般不提供，显示“读不到”）、是否接通电源 / 电量、当前方案的最大处理器状态（交流 / 电池）和散热方式。
- **切换电源方案**（节能 / 平衡 / 高性能等，只能选列表里已有的方案）。
- **降温模式**：把当前方案的“最大处理器状态”降到 70 / 80 / 90 / 99 / 100%，并把散热方式设为“主动”。**99% 会关闭睿频**，通常是降温最明显、对日常使用影响最小的选择。
- 第一次修改前会自动备份原来的方案和数值；“恢复原设置”回到 NetPet 第一次修改之前。修改是持久的：**退出 NetPet 不会自动恢复**，卸载前如果想恢复请先点“恢复原设置”。手动恢复方法见《排障说明》。
- **温度过高自动降温**（默认关闭）：CPU 温度持续 60 秒 ≥ 阈值（80 / 85 / 90℃）→ 临时进入降温模式；低于阈值 10℃ 持续 5 分钟 → 恢复；两次之间至少隔 10 分钟。读不到温度时不工作（页面会提示）。
- **电量低时自动切换到节能方案**（默认关闭）：用电池且电量 ≤ 设定值时切到“节能”；接通电源或电量回升 10% 以上时恢复。没有“节能”方案的电脑（新式待机机型常见）不起作用。
- **NetPet 不直接控制风扇**：那需要内核驱动或厂商 EC 访问，不安全、会被杀毒软件拦截，而且每台电脑都不一样。想调风扇曲线请用厂商工具（如 Armoury Crate、Lenovo Vantage、MSI Center、Dell Power Manager、OMEN Gaming Hub）或 BIOS。
