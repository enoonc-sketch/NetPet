# NetPet 隐私说明与数据流审查（v1.5.0）

> 一句话：**NetPet 没有服务器，不收集、不上传你的任何数据。** 默认设置下只读取本机信息，**完全不联网**。
> 下面列出的几个功能会产生网络流量或修改系统设置，**全部默认关闭或只在你点击时运行**。

## 1. 会联网的功能（共 7 项，代码已逐项核对）

| 功能 | 默认 | 什么时候联网 | 连到哪里 | 对方能看到什么 | NetPet 发送的本机数据 |
|---|---|---|---|---|---|
| 解析主机名（反向 DNS） | 关闭 | 开启“连接记录”+“解析主机名”后，每条新连接查一次 | 你的系统 DNS 服务器（通常是路由器/运营商） | 你连接过的对方 IP | 无（只有要查的 IP） |
| 真实联网检测 | 关闭 | 开启后每 30 秒一次 | `http://www.msftconnecttest.com/connecttest.txt`（微软，与 Windows 自带联网检测同一地址） | 你的公网 IP、请求时间、User-Agent “NetPet” | 无，不带 Cookie |
| 系统更新 → 检查可用更新 | 只在你点击时 | 点“检查可用更新”时一次 | 由 **Windows 更新服务**联系微软更新服务器（或公司 WSUS） | 与你在“设置 → Windows 更新”里点检查更新完全相同 | NetPet 本身不发送任何数据 |
| 驱动更新 → 在线检查可用驱动（1.5.0） | 只在你点击时 | 点“在线检查可用驱动”时一次 | 由 **Windows 更新服务**（Windows Update Agent，搜索 `IsInstalled=0 and Type='Driver'`）联系微软更新服务器（或公司 WSUS） | 与在“Windows 更新 → 可选更新”里检查完全相同 | NetPet 本身不发送任何数据；只读取结果列表，不下载、不安装 |
| 病毒查杀 → 更新病毒库（1.5.0） | 只在你点击时 | 点“更新病毒库”时一次 | 由 **Microsoft Defender**（`Update-MpSignature` / `MpCmdRun -SignatureUpdate`）联系微软更新服务器 | 与在 Windows 安全中心点“检查更新”相同 | NetPet 本身不发送任何数据 |
| 检查 NetPet 新版本 | 只在你点击时 | 点“检查新版本”时一次 | `https://api.github.com/repos/enoonc-sketch/NetPet/releases/latest`（GitHub） | 你的公网 IP、请求时间、User-Agent “NetPet/版本号” | 无。只读取最新版本号和发布说明；发现新版本时只打开发布页，不自动下载或安装 |
| VPN（sing-box） | 只在你点击连接时 | 连接期间 | **你配置文件里写的服务器** | 取决于你的配置：经过 VPN 的网络流量会交给该服务器 | NetPet 不读取、不记录、不转发任何流量内容；转发由 sing-box 完成 |

补充说明：
- **VPN 是最需要你自己判断的一项**：NetPet 不提供、不推荐任何服务器，不下载 sing-box，不拉取订阅。你的流量交给谁，完全由你选的配置决定。请只使用你信任的服务，并遵守当地法律法规。
- “系统更新 → 只看本机状态”**不联网**，只读注册表和补丁记录。
- 你主动点击（或开启“定期快速扫描”后）的 **Defender 扫描**由 Microsoft Defender 执行，它是否联网（如云保护、样本提交）由 Defender 自己的设置决定，NetPet 不修改这些设置。
- “驱动更新”页打开时读取的本机驱动列表、“磁盘整理”“温度与节能”“任务管理器”“运行内存”页的所有读取都**不联网**。
- “打开 Windows 更新”“打开任务管理器”只是打开系统自带的页面，不产生网络请求。

## 2. 不会联网的部分
- 网速、硬件状态、进程排行、连接记录（不开反向 DNS 时）、新程序首次联网提醒、流量额度、久坐/喝水提醒、系统健康检查（含硬盘/电池健康）、诊断包导出、全屏检测、启动管理、系统清理、系统更新的本机状态：只读取本机系统计数器、系统命令输出和本地文件。
- 1.5.0 新增且**不联网**的：中英文界面、网速异常提醒、番茄钟、硬件历史曲线、每周使用小结（完全本地生成）、宠物换装、驱动本机列表、病毒查杀的状态 / 扫描 / 威胁记录（扫描时 Defender 自身的云保护除外）、任务管理器、运行内存页、磁盘整理、温度与节能。
- **没有**自动更新（只有点击才运行的“检查新版本”）、崩溃上报、使用统计、广告、遥测。代码中没有 `autoUpdater`、`crashReporter`、`fetch`、`XMLHttpRequest`、`WebSocket`、`sendBeacon`。
- 三个界面页面的内容安全策略（CSP）都是 `default-src 'self'`：界面本身不能请求任何远程地址，也不加载远程脚本或图片。上表中的联网都发生在主进程或 Windows 自己的服务里。
- 主进程里会产生网络流量的代码只有：`dns.reverse`（反向 DNS）、`http.get`（联网检测，固定地址）、`https.get`（检查新版本，固定地址）、启动 sing-box 子进程（VPN）、调用 Windows Update Agent（检查系统更新、1.5.0 的驱动在线检查）、调用 Defender 更新病毒库（1.5.0）。

## 3. 会修改系统的功能（都需要你主动点击，都可以撤销）

| 功能 | 改什么 | 怎么撤销 |
|---|---|---|
| 开机自启 | Windows 登录项里加入 NetPet | 关闭开关；卸载时清除 |
| 系统清理 | 删除白名单目录里的垃圾文件（临时文件只删 24 小时以前的、浏览器缓存、崩溃转储、回收站、NetPet 旧日志） | **删除不可恢复**，清理前会列出类别和大小让你确认。绝不碰文档、下载、桌面、图片、程序文件、系统日志 |
| 启动管理 | 只改当前用户启动项的启用标记（与任务管理器相同），不删除启动项 | 在启动管理或任务管理器里重新启用 |
| VPN | 连接期间把系统代理设为 `127.0.0.1:端口`（可关闭此选项） | 断开、sing-box 意外退出、退出 NetPet 时自动恢复原设置；NetPet 崩溃则下次启动时恢复 |
| 运行内存整理 | 对当前用户的后台程序调用 EmptyWorkingSet（手动点击；开启“自动整理”后内存持续高于阈值时；1.5.0 开启“定期整理”后在你离开电脑时） | 无需撤销：不关闭程序、不改设置，程序再用到时自动取回内存；可设排除列表 |
| Defender 快速扫描 | 让 Defender 执行一次快速扫描 | 不改设置 |
| 病毒查杀（1.5.0） | 让 Microsoft Defender 执行快速 / 全盘 / 自定义扫描或更新病毒库；**离线扫描会立即重启电脑**（两次确认）。可选“定期快速扫描”（默认关闭） | 不改 Defender 的任何设置、排除项和实时保护；不删除 / 隔离 / 放行威胁（由你在 Windows 安全中心处理） |
| 任务管理器（1.5.0） | 结束你选中的进程 / 进程树（先正常结束，再询问是否强制）、把优先级设为 低于正常 / 正常 / 高于正常 | 每次都要确认；系统关键进程、杀毒进程和 NetPet 自己不能结束；结束的进程无法“撤销”，可以重新打开程序；优先级重启程序后恢复。所有操作写入本地日志 |
| 磁盘整理（1.5.0） | 调用 Windows 自带 `Optimize-Volume`：HDD 碎片整理、SSD 只做 TRIM，类型未知跳过；可选“每周自动优化”（默认关闭，不创建系统计划任务） | 优化本身不需要撤销（与 Windows 每周自动优化相同）；需要管理员；用电池时不运行 |
| 温度与节能（1.5.0） | 切换电源方案；修改当前方案的“最大处理器状态”（PROCTHROTTLEMAX）和“系统散热方式”（SYSCOOLPOL）；可选“温度过高自动降温”“低电量自动切节能”（都默认关闭） | 第一次修改前自动备份原值，“恢复原设置”一键恢复；修改是持久的，退出 NetPet 不会自动恢复；手动恢复：`powercfg -restoredefaultschemes`。**不直接控制风扇** |

除上表外，所有检查用的 PowerShell 命令都是只读的（Get-* / 查询类）。NetPet 不会**自动**结束任何程序（只有你在任务管理器里确认后才会结束），不会安装更新或驱动，除你确认的“离线扫描”外不会重启电脑。

## 4. 本机保存了什么

| 数据 | 位置 | 内容 | 如何删除 |
|---|---|---|---|
| 统计数据库 | `%APPDATA%\NetPet\data\netpet.db` | 每日流量、网卡信息、连接记录（开启时：程序名、对方 IP/端口/主机名）、每分钟硬件采样、体检结果、提醒 | 隐私页“清空全部历史数据”；或按保留天数（7/30/90）自动清理 |
| 设置 | 同一数据库的 settings 表 | 开关、宠物、hosts/代理的“内容指纹”、上次更新检查结果；**加密保存**：面板密码哈希（scrypt + 随机盐，不保存明文）、sing-box 程序和配置的路径、VPN 连接前的代理备份 | 删除数据库 |
| 新程序首次联网 | settings 表 | 开启后已见过的程序名列表（最多 3000 个） | 关闭再开启即清空；或删除数据库 |
| 日志 | `%APPDATA%\NetPet\logs\` | 启动步骤、错误、卡顿、你执行过的清理/启动项修改/VPN 连接（不含任何监控数据，最多 5 个文件，每个约 1MB） | 直接删除，或系统清理 → NetPet 旧日志 |
| sing-box 工作目录 | `%APPDATA%\NetPet\sing-box\` | sing-box 自己写的缓存（如规则集缓存），取决于你的配置 | 直接删除 |

- **诊断包**只在你点击“导出诊断包”时生成到你选的位置，内容是日志 + 版本/系统信息 + 开关状态，**不含**统计数据、连接记录、密码、VPN 路径和配置；NetPet 不会自动发送。
- **设置导出文件**（1.4.0）：只在你点击“导出设置”时写到你选择的位置，内容是偏好设置（开关、宠物、提醒、快捷键等），不含任何敏感信息或统计数据。NetPet 不会自动导出或发送。
- **1.5.0 新增的本机数据**：`daily_counters`（每天的提醒次数、番茄钟个数 / 分钟、当天 CPU 峰值，保留 400 天）、`weekly_summary`（每周小结，最多 60 份）、`memtrim_runs`（最近 20 次内存整理的效果）；设置里新增语言、网速提醒、番茄钟、外观、自动任务开关、电源设置备份（原方案 GUID 和数值）、上次驱动在线检查结果（驱动更新标题列表）、上次病毒库更新结果。“清空全部历史数据”会清空三张新表。
- **1.5.0 不保存**：任务管理器的进程列表 / 命令行 / 签名结果（只在内存里缓存）、服务列表、驱动本机列表、Defender 状态和威胁记录（每次打开页面重新读取，威胁记录本来就由 Windows 保存）。
- **不保存**：sing-box 的运行日志（只在内存里保留最近几百行）、进程排行、启动项列表、联网检测结果、任何通信内容。
- **你的 sing-box 配置文件**（含服务器地址和密钥）NetPet 只读取、不复制、不修改，留在你自己选的位置。
- **敏感设置加密**（1.3.3）：面板密码哈希、sing-box 路径、VPN 代理备份用 Electron `safeStorage` 加密，Windows 上即 DPAPI，绑定当前 Windows 用户。数据库被拷到别的电脑或别的账户时这几项解不开，会被重置（密码失效需重设，VPN 需重新选择文件）。隐私页“数据管理”里显示加密是否可用。
- **局限**：DPAPI 挡不住以你的身份运行的其他程序；**统计数据（流量、连接记录、硬件历史）没有加密**。面板密码锁只防随手查看，共用电脑请注意。
- 导出 CSV、备份数据库只写到你在对话框里选择的位置。

## 5. 不采集的内容
- 不读取数据包或通信内容，不做 TLS 解密：只用连接表（元数据）和网卡计数器。
- 不记录键盘输入、屏幕截图、浏览器历史、用户文件。
- 全屏检测只问 Windows “现在是否有全屏程序”，不读取任何窗口标题或内容。

## 6. 默认状态一览
默认开启：网络速度监控、硬件状态监控（都只读本机、不联网）。
默认关闭：连接记录、解析主机名、进程排行、系统健康检查、全屏自动隐藏、真实联网检测、开机自启、VPN、运行内存自动整理与定期整理、新程序首次联网提醒、流量额度（额度为 0）、久坐/喝水提醒、网速异常提醒（1.5.0）、磁盘每周自动优化（1.5.0）、温度过高自动降温（1.5.0）、低电量自动切节能（1.5.0）、Defender 定期快速扫描（1.5.0）、任务管理器快捷键（1.5.0）。
默认开启（1.5.0）：每周使用小结（完全本地，可在“每周小结”页关闭）。
安全模式下：除网速外全部强制关闭，VPN 不允许启动；1.5.0 起所有自动修改系统的功能（磁盘自动整理、自动降温、低电量节能、定期扫描、定期内存整理）也不运行，电源设置和磁盘优化按钮不可用。

## 7. 审查方法与局限
- 1.5.0 复查：新增模块中会联网的只有两处，且都只在点击时运行、由 Windows 组件自己完成：`drivers.ts` 的 WUA 驱动搜索、`defender.ts` 的 `Update-MpSignature`。`i18n.ts`、`speedalert.ts`、`focus.ts`、`weekly.ts`、`sched.ts`、`series.ts`、`wardrobe.ts`、`procview.ts` 是纯函数，没有任何 I/O；`power.ts`、`diskopt.ts`、`procmgr.ts`、`memtrim.ts` 只调用本机命令。界面 CSP 不变，新页面没有加载任何远程资源。
- 1.4.0 复查：新增代码（`settingsio.ts`、`hotkey.ts`、`report.ts`、相关 IPC 与界面）没有任何网络调用；全局快捷键只注册你选择的那一个组合键，不记录、不监听其他键盘输入。
- 方法：开发者对 `src/` 全部源码逐文件检查网络调用（`http`、`https`、`dns`、`net`、`fetch`、`WebSocket`、子进程命令）和写操作（文件删除、注册表写入），结果如上。
- 这是**开发者自查，不是第三方安全审计**。
- 未包含依赖库（Electron、systeminformation、three.js、React）和 sing-box 本身的审计；发布前建议运行 `npm audit`。
- v1.3.3 新增的联网检测、VPN、系统更新、启动管理、系统清理改动**尚未在真实 Windows 上测试**。

## 版本记录
- v1.5.0：联网功能 5 → 7 项（新增“驱动在线检查”“更新病毒库”，都只在点击时运行，由 Windows 更新服务 / Microsoft Defender 自己联系微软）。新增会修改系统的功能：任务管理器（结束进程 / 优先级，每次确认，受保护名单）、磁盘整理（Optimize-Volume，SSD 只 TRIM）、温度与节能（电源方案 / 最大处理器状态，先备份）、病毒查杀（只发起 Defender 扫描，离线扫描会重启）、运行内存定期整理；所有自动执行的版本都默认关闭，安全模式下不运行，设置导入也不会打开它们。每周小结默认开启但完全本地。
