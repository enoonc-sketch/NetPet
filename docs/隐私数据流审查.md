# NetPet 隐私说明与数据流审查（v1.3.3）

> 一句话：**NetPet 没有服务器，不收集、不上传你的任何数据。** 默认设置下只读取本机信息，**完全不联网**。
> 下面列出的几个功能会产生网络流量或修改系统设置，**全部默认关闭或只在你点击时运行**。

## 1. 会联网的功能（共 5 项，代码已逐项核对）

| 功能 | 默认 | 什么时候联网 | 连到哪里 | 对方能看到什么 | NetPet 发送的本机数据 |
|---|---|---|---|---|---|
| 解析主机名（反向 DNS） | 关闭 | 开启“连接记录”+“解析主机名”后，每条新连接查一次 | 你的系统 DNS 服务器（通常是路由器/运营商） | 你连接过的对方 IP | 无（只有要查的 IP） |
| 真实联网检测 | 关闭 | 开启后每 30 秒一次 | `http://www.msftconnecttest.com/connecttest.txt`（微软，与 Windows 自带联网检测同一地址） | 你的公网 IP、请求时间、User-Agent “NetPet” | 无，不带 Cookie |
| 系统更新 → 检查可用更新 | 只在你点击时 | 点“检查可用更新”时一次 | 由 **Windows 更新服务**联系微软更新服务器（或公司 WSUS） | 与你在“设置 → Windows 更新”里点检查更新完全相同 | NetPet 本身不发送任何数据 |
| 检查 NetPet 新版本 | 只在你点击时 | 点“检查新版本”时一次 | `https://api.github.com/repos/enoonc-sketch/NetPet/releases/latest`（GitHub） | 你的公网 IP、请求时间、User-Agent “NetPet/版本号” | 无。只读取最新版本号和发布说明；发现新版本时只打开发布页，不自动下载或安装 |
| VPN（sing-box） | 只在你点击连接时 | 连接期间 | **你配置文件里写的服务器** | 取决于你的配置：经过 VPN 的网络流量会交给该服务器 | NetPet 不读取、不记录、不转发任何流量内容；转发由 sing-box 完成 |

补充说明：
- **VPN 是最需要你自己判断的一项**：NetPet 不提供、不推荐任何服务器，不下载 sing-box，不拉取订阅。你的流量交给谁，完全由你选的配置决定。请只使用你信任的服务，并遵守当地法律法规。
- “系统更新 → 只看本机状态”**不联网**，只读注册表和补丁记录。
- 你主动点击的 **Defender 快速扫描**由 Windows Defender 执行，它是否联网（如云保护）由 Defender 自己的设置决定。
- “打开 Windows 更新”“打开任务管理器”只是打开系统自带的页面，不产生网络请求。

## 2. 不会联网的部分
- 网速、硬件状态、进程排行、连接记录（不开反向 DNS 时）、新程序首次联网提醒、流量额度、久坐/喝水提醒、系统健康检查（含硬盘/电池健康）、诊断包导出、全屏检测、启动管理、系统清理、系统更新的本机状态：只读取本机系统计数器、系统命令输出和本地文件。
- **没有**自动更新（只有点击才运行的“检查新版本”）、崩溃上报、使用统计、广告、遥测。代码中没有 `autoUpdater`、`crashReporter`、`fetch`、`XMLHttpRequest`、`WebSocket`、`sendBeacon`。
- 三个界面页面的内容安全策略（CSP）都是 `default-src 'self'`：界面本身不能请求任何远程地址，也不加载远程脚本或图片。上表中的联网都发生在主进程或 Windows 自己的服务里。
- 主进程里会产生网络流量的代码只有：`dns.reverse`（反向 DNS）、`http.get`（联网检测，固定地址）、`https.get`（检查新版本，固定地址）、启动 sing-box 子进程（VPN）、调用 Windows Update Agent（检查更新）。

## 3. 会修改系统的功能（都需要你主动点击，都可以撤销）

| 功能 | 改什么 | 怎么撤销 |
|---|---|---|
| 开机自启 | Windows 登录项里加入 NetPet | 关闭开关；卸载时清除 |
| 系统清理 | 删除白名单目录里的垃圾文件（临时文件只删 24 小时以前的、浏览器缓存、崩溃转储、回收站、NetPet 旧日志） | **删除不可恢复**，清理前会列出类别和大小让你确认。绝不碰文档、下载、桌面、图片、程序文件、系统日志 |
| 启动管理 | 只改当前用户启动项的启用标记（与任务管理器相同），不删除启动项 | 在启动管理或任务管理器里重新启用 |
| VPN | 连接期间把系统代理设为 `127.0.0.1:端口`（可关闭此选项） | 断开、sing-box 意外退出、退出 NetPet 时自动恢复原设置；NetPet 崩溃则下次启动时恢复 |
| 运行内存整理 | 对当前用户的后台程序调用 EmptyWorkingSet（手动点击，或开启“自动整理”后内存持续高于阈值时） | 无需撤销：不关闭程序、不改设置，程序再用到时自动取回内存 |
| Defender 快速扫描 | 让 Defender 执行一次快速扫描 | 不改设置 |

除上表外，所有检查用的 PowerShell 命令都是只读的（Get-* / 查询类）。NetPet 不会自动结束任何程序，不会安装更新，不会重启电脑。

## 4. 本机保存了什么

| 数据 | 位置 | 内容 | 如何删除 |
|---|---|---|---|
| 统计数据库 | `%APPDATA%\NetPet\data\netpet.db` | 每日流量、网卡信息、连接记录（开启时：程序名、对方 IP/端口/主机名）、每分钟硬件采样、体检结果、提醒 | 隐私页“清空全部历史数据”；或按保留天数（7/30/90）自动清理 |
| 设置 | 同一数据库的 settings 表 | 开关、宠物、hosts/代理的“内容指纹”、上次更新检查结果；**加密保存**：面板密码哈希（scrypt + 随机盐，不保存明文）、sing-box 程序和配置的路径、VPN 连接前的代理备份 | 删除数据库 |
| 新程序首次联网 | settings 表 | 开启后已见过的程序名列表（最多 3000 个） | 关闭再开启即清空；或删除数据库 |
| 日志 | `%APPDATA%\NetPet\logs\` | 启动步骤、错误、卡顿、你执行过的清理/启动项修改/VPN 连接（不含任何监控数据，最多 5 个文件，每个约 1MB） | 直接删除，或系统清理 → NetPet 旧日志 |
| sing-box 工作目录 | `%APPDATA%\NetPet\sing-box\` | sing-box 自己写的缓存（如规则集缓存），取决于你的配置 | 直接删除 |

- **诊断包**只在你点击“导出诊断包”时生成到你选的位置，内容是日志 + 版本/系统信息 + 开关状态，**不含**统计数据、连接记录、密码、VPN 路径和配置；NetPet 不会自动发送。
- **不保存**：sing-box 的运行日志（只在内存里保留最近几百行）、进程排行、启动项列表、联网检测结果、任何通信内容。
- **你的 sing-box 配置文件**（含服务器地址和密钥）NetPet 只读取、不复制、不修改，留在你自己选的位置。
- **敏感设置加密**（1.3.3）：面板密码哈希、sing-box 路径、VPN 代理备份用 Electron `safeStorage` 加密，Windows 上即 DPAPI，绑定当前 Windows 用户。数据库被拷到别的电脑或别的账户时这几项解不开，会被重置（密码失效需重设，VPN 需重新选择文件）。隐私页“数据管理”里显示加密是否可用。
- **局限**：DPAPI 挡不住以你的身份运行的其他程序；**统计数据（流量、连接记录、硬件历史）没有加密**。面板密码锁只防随手查看，共用电脑请注意。
- 导出 CSV、备份数据库只写到你在对话框里选择的位置。

## 5. 不采集的内容
- 不读取数据包或通信内容，不做 TLS 解密：只用连接表（元数据）和网卡计数器。
- 不记录键盘输入、屏幕截图、浏览器历史、用户文件。
- 全屏检测只问 Windows “现在是否有全屏程序”，不读取任何窗口标题或内容。

## 6. 默认状态一览
默认开启：网络速度监控、硬件状态监控（都只读本机、不联网）。
默认关闭：连接记录、解析主机名、进程排行、系统健康检查、全屏自动隐藏、真实联网检测、开机自启、VPN、运行内存自动整理、新程序首次联网提醒、流量额度（额度为 0）、久坐/喝水提醒。
安全模式下：除网速外全部强制关闭，VPN 不允许启动。

## 7. 审查方法与局限
- 方法：开发者对 `src/` 全部源码逐文件检查网络调用（`http`、`https`、`dns`、`net`、`fetch`、`WebSocket`、子进程命令）和写操作（文件删除、注册表写入），结果如上。
- 这是**开发者自查，不是第三方安全审计**。
- 未包含依赖库（Electron、systeminformation、three.js、React）和 sing-box 本身的审计；发布前建议运行 `npm audit`。
- v1.3.3 新增的联网检测、VPN、系统更新、启动管理、系统清理改动**尚未在真实 Windows 上测试**。
