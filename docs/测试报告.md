## 你在 Windows 上的建议测试步骤
1. `build.bat` 打包 → 安装 → 确认桌面有快捷方式，宠物出现，托盘有图标。
2. 隐私页逐项开关，确认关闭后对应数据不再增长。
3. 打开“系统健康”，点开始体检，核对 Defender/防火墙结果是否与 Windows 安全中心一致。
4. 拔网线/关 Wi-Fi，看是否提示“网络已断开”，恢复后是否提示“网络已恢复”。
5. 电脑休眠再唤醒，看网速是否出现一个异常大的数字。
6. 开启“全屏时自动隐藏”，打开全屏视频，看宠物是否隐藏。
7. 退出软件后，在任务管理器里确认没有残留的 NetPet、powershell 进程。
8. 卸载，确认会询问是否删除数据，开机自启项被清除。
9. ETW：先跑 `native\procnet\build.bat` 编译出 `procnet.node`，再跑根目录 `build.bat` 打包安装；以管理员身份运行，到隐私页打开“按程序统计流量（ETW）”，B 区应出现排行。
10. ETW 校准：下一个大文件，同时打开资源监视器 → 网络 → 有网络活动的进程，对比该程序的速率和累计量（数量级应对得上）；看 B 区“解析失败”是否在涨——涨就说明 size 偏移要校准，停用该功能并把数字发给我。
11. ETW 非管理员：普通身份运行一次，B 区应显示“需要管理员权限”，不弹 UAC、不崩溃；退出后 `logman query -ets` 看不到残留的 NetPet-ProcNet 会话。
