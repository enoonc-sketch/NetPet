# NetPet v1.3.1 测试报告

**重要说明**：以下测试在 Linux 沙箱里完成（Electron 37 + 软件渲染 + 虚拟显示）。**没有在真实 Windows 上测试过**。规范要求的 Windows 实机测试需要你来跑，清单见文末。

## v1.3.1：修复“启动无响应”后的验证
- 采集进程隔离：在真实 Electron 里验证采集请求（CPU、磁盘、进程等）通过独立进程返回正常；也验证了从 `app.asar` 打包形态运行同样正常。
- 启动标记：宠物画出第一帧、采样跑起来后标记被清除；残留标记会触发安全模式；安全模式保持到用户主动退出；`--safe` 参数有效；安全模式下 3D、硬件监控等被关闭，界面顶部有提示。
- **没法在沙箱里验证的**：Windows 上的卡死本身（我没有复现环境）、Get-NetAdapterStatistics 网速采集器、PowerShell 常驻进程。这些必须在你的电脑上确认。

## v1.3 变更与验证
v1.3 把代码迁移到 TypeScript + React，并新增紧凑模式。迁移后重新验证：
- `tsc --noEmit` 类型检查通过；`npm test` 单元测试通过。
- 真实 Electron 端到端测试通过（首次使用隐私页、3D 宠物、6 个页签、小面板、暂停、非法参数/越权调用被拒绝），页面无控制台错误。
- 紧凑模式：窗口 170×190 ⇄ 96×100 切换正常，并保持右下角位置不变。
- `electron-builder --win dir` 打包通过，包内只含 `out/` 与 `systeminformation`。
- 本版没有重新做过的：下面“未能测试”表里的 Windows 实机项目，依旧需要你来测。

## 你在 Windows 上的建议测试步骤
1. `build.bat` 打包 → 安装 → 确认桌面有快捷方式，宠物出现，托盘有图标。
2. 隐私页逐项开关，确认关闭后对应数据不再增长。
3. 打开“系统健康”，点开始体检，核对 Defender/防火墙结果是否与 Windows 安全中心一致。
4. 拔网线/关 Wi-Fi，看是否提示“网络已断开”，恢复后是否提示“网络已恢复”。
5. 电脑休眠再唤醒，看网速是否出现一个异常大的数字。
6. 开启“全屏时自动隐藏”，打开全屏视频，看宠物是否隐藏。
7. 退出软件后，在任务管理器里确认没有残留的 NetPet、powershell 进程。
8. 卸载，确认会询问是否删除数据，开机自启项被清除。
