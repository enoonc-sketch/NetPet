## 你在 Windows 上的建议测试步骤
**v1.3.2 新增（重点测这三项）：**
1. 宠物防消失：把宠物拖到屏幕边缘/角落，看是否拖不出去；改分辨率或拔掉副屏再启动，看宠物是否回到主屏右下角；单击托盘图标，看宠物是否不再被误隐藏（已隐藏时单击应恢复）。
2. 一键复位：把宠物拖到别处、手动隐藏一次，再分别从托盘菜单、右键菜单、主面板设置页点一键复位，看是否回到右下角并显示；确认宠物种类和数据没变。
3. 系统清理：打开主面板 → 系统清理，点重新扫描，核对各类别大小是否合理；先只勾“用户临时文件”清理一次，确认能释放空间、正在使用的文件被跳过；回收站务必确认里面没有要留的文件再勾选。
**v1.3.1 及之前：**
1. `build.bat` 打包 → 安装 → 确认桌面有快捷方式，宠物出现，托盘有图标。
2. 隐私页逐项开关，确认关闭后对应数据不再增长。
3. 打开“系统健康”，点开始体检，核对 Defender/防火墙结果是否与 Windows 安全中心一致。
4. 拔网线/关 Wi-Fi，看是否提示“网络已断开”，恢复后是否提示“网络已恢复”。
5. 电脑休眠再唤醒，看网速是否出现一个异常大的数字。
6. 开启“全屏时自动隐藏”，打开全屏视频，看宠物是否隐藏。
7. 退出软件后，在任务管理器里确认没有残留的 NetPet、powershell 进程。
8. 卸载，确认会询问是否删除数据，开机自启项被清除。
