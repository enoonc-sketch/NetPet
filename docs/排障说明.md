# NetPet 排障说明

## 如果启动后卡住 / 无响应
1. 先用 **“NetPet-安全模式.bat”** 启动（免安装版自带；源码版可在命令行运行 `NetPet.exe --safe`）。安全模式会关闭硬件加速、3D 宠物（改用 emoji 宠物）和所有可选监控，只保留网速。
2. **自动保护**：如果上一次启动没有完成（卡死、崩溃、被你强制结束，或开机后几秒就关机），下一次会自动进入安全模式，并一直保持，直到你在“完整窗口”顶部点 **“重启并退出安全模式”**。1.3.3 起，在安全模式下启动会弹通知并自动打开主面板，不会再悄悄关掉功能。
   安全模式下你在隐私页改的开关只对本次生效，不会覆盖原来的设置；退出安全模式后恢复你之前的选择。
3. 安全模式下能正常用的话，说明问题出在 3D/显卡 或某个可选监控上。请把下面的日志发给我。

## 日志在哪里
`%APPDATA%\NetPet\logs\netpet.log`（在资源管理器地址栏粘贴这个路径即可）。
1.3.3 起日志超过 1MB 会换新文件，旧文件名形如 `netpet-2026-11-22T08-00-00-000Z.log`，最多保留 5 个。发日志时请把这个文件夹里的文件一起发。
日志只记录：启动步骤、错误、窗口无响应、采集超时，**不记录任何监控数据**。
**最简单的办法**：主面板 → 隐私 → 数据管理 → **导出诊断包**，把生成的 zip 发给我（已包含日志、版本和系统信息，不含你的统计数据和密码）。打不开主面板时再手动发日志文件夹。另外请告诉我：Windows 版本、显卡型号、是否装了代理/VPN/虚拟机/杀毒软件。

## 手动恢复
- 想强制回到正常模式：退出 NetPet，删除 `%APPDATA%\NetPet\starting.flag` 和 `%APPDATA%\NetPet\safe.mode` 再启动。
- 想彻底重置：退出 NetPet，删除整个 `%APPDATA%\NetPet` 文件夹（会丢失所有数据）。

## 忘记面板密码
面板密码锁的作用是防止别人随手查看或误操作，**不是加密**：数据库文件本身没有加密。忘记密码时有两种办法：

**说明**：1.3.3 起密码哈希加密保存，数据库里 `lock` 这一项是一段密文，但删除方法不变。

**办法一：只清除密码，保留所有数据（推荐）**
1. 退出 NetPet（右键托盘图标 → 退出软件），确认任务管理器里没有 NetPet 进程。
2. 先备份 `%APPDATA%\NetPet\data\netpet.db`，复制一份即可。
3. 用任意 SQLite 工具打开它，例如免费的 [DB Browser for SQLite](https://sqlitebrowser.org/)，或者命令行 `sqlite3`。
4. 执行：`DELETE FROM settings WHERE key = 'lock';` 然后保存（写入更改）。
5. 重新启动 NetPet，面板不再需要密码。

**办法二：重置全部数据**
退出 NetPet，删除 `%APPDATA%\NetPet\data` 文件夹里的 `netpet.db`、`netpet.db-wal`、`netpet.db-shm`。所有设置和历史统计都会丢失。

说明：1.3.3 起，上锁时导出、清空、改设置、清理等操作在后台也会被拒绝，关闭主面板后会自动重新上锁。所以如果某个按钮点了没反应，先确认面板是否已解锁。

## 换电脑 / 重装系统后密码失效、VPN 要重新选文件
1.3.3 起面板密码、sing-box 路径和 VPN 代理备份用当前 Windows 账户加密（DPAPI）。把 `%APPDATA%\NetPet` 拷到别的电脑、别的账户，或重装系统后，这几项无法解密，会自动重置：密码移除（会弹通知）、VPN 需要重新选择程序和配置。统计数据和其他设置不受影响。日志里会有“敏感设置 … 无法解密”的记录。

## 提示“已连接但上不了网”或“需要网页登录”
这两条提示只在打开了 **隐私 → 真实联网检测** 时才会出现（默认关闭）。检测方式：每 30 秒请求一次 Windows 自带联网检测使用的同一个地址 `http://www.msftconnecttest.com/connecttest.txt`，连续 2 次结果相同才改变状态。

- **需要网页登录**：一般是酒店、机场、公司访客 Wi-Fi。打开浏览器访问任意网页，按提示登录即可。约 1 分钟后提示自动消失。
- **已连接但上不了网**：电脑连着路由器，但访问不到互联网。按顺序检查：其他设备能否上网（判断是不是宽带或路由器的问题）→ 重启路由器 → 检查系统代理和 VPN 设置。
- **能正常上网却一直提示（误报）**，常见原因有：
  1. 公司网络或防火墙拦截了 `msftconnecttest.com`。用浏览器打开上面的地址，正常应该只显示一行 `Microsoft Connect Test`。
  2. 代理或翻墙软件只代理浏览器，没有接管普通程序的 HTTP 请求（NetPet 不走系统代理设置）。
  3. 公司 DNS 把这个域名解析到了内网服务器，返回的内容不对，就会被判为“需要网页登录”。
  遇到这几种情况，直接关闭“真实联网检测”即可。关闭后只根据本机有没有 IP 地址判断是否断网，其他功能不受影响。
- 没开这个检测却提示“网络已断开”：说明本机确实没有可用的 IPv4 或公网 IPv6 地址（只有 169.254.x.x 或 fe80:: 这类自动地址）。请检查网线、Wi-Fi 或网卡驱动。1.3.3 起，纯 IPv6 网络不再误报断网。

## 系统健康检查的结果看起来不对
- **装了第三方杀毒（如火绒、360、卡巴斯基）**：1.3.3 起会读取 Windows 安全中心登记的杀毒和防火墙产品，显示“由第三方杀毒软件提供保护”，不再误判为“实时保护已关闭”。如果仍然显示异常，说明该软件没有在 Windows 安全中心登记，请在它自己的界面里确认防护状态。
- **“本机监听端口”比以前多了提醒**：1.3.3 修复了漏检问题。以前监听在 0.0.0.0（所有网卡）上的端口被错误排除，而这类端口恰恰是对外开放的。现在出现 445（文件共享）、3389（远程桌面）等提醒是正常的，按建议确认是否需要开启即可。
- **警示牌一直不消失**：1.3.3 起每 6 小时自动复查一次，问题解决后会自动消失。也可以在主面板 → 系统健康里点“重新体检”。
- **Defender 快速扫描提示“没有成功完成”**：可能需要管理员权限，或者 Defender 处于被动模式（装了其他杀毒软件）。可以改在 Windows 安全中心里手动扫描。

## 流量额度 / 首次联网 / 久坐提醒
- **流量额度提醒没出现**：需要“网络速度监控”开启；同一档（80%、100%）每月只提醒一次，改额度后会重新计算；勿扰模式下只更新气泡、不弹通知。统计的是网卡总流量（含局域网传输），可能比运营商的计数略高。
- **首次联网提醒太多**：开启后前 24 小时是学习期；学习期结束后，新装的软件、软件更新带来的新进程名都会提醒一次，之后不再重复。觉得烦可以关掉。
- **首次联网提醒一直不出现**：要同时开启“网络使用统计（连接记录）”；只看对外的新建连接，本机和局域网连接不算。
- **久坐提醒不准**：按 Windows 报告的“键鼠空闲时间”判断你是否在用电脑。看视频不动鼠标超过 5 分钟会被当成休息。全屏、勿扰时不提醒。

## 硬盘 / 电池健康显示“无法检测”
部分 USB 移动硬盘、RAID 阵列、虚拟机磁盘不提供健康数据；寿命和错误计数在非管理员或部分硬盘上读不到，这时只显示健康状态。电池容量由电池固件提供，个别品牌数据不准，明显异常时 NetPet 不下结论。

## 运行内存整理
- **整理后内存很快又涨回来**：正常现象。程序会按需取回内存，整理只能暂时腾出空间。经常超过 90% 说明内存确实不够用，请在资源占用排行里找出占用大的程序关掉。
- **整理后某个程序卡了一下**：它的内存被交还给系统，再次用到时要从压缩区或页面文件取回。介意的话关闭“自动整理”，只在需要时手动点。
- **“处理了 0 个程序”或提示失败**：安全软件可能拦截了 PowerShell 或进程访问；以管理员身份运行时才能处理其他账户/服务的进程，普通运行只处理你自己的程序，这是有意的。
- **自动整理一直没触发**：需要“硬件状态监控”开启，并且内存持续 1 分钟超过阈值；两次之间至少隔 10 分钟；安全模式下自动整理关闭。

## 检查新版本失败
- **“连接 GitHub 超时”/“连不上 GitHub”**：所在网络访问 GitHub 不稳定。可以先连上 VPN 再检查，或直接在浏览器打开 https://github.com/enoonc-sketch/NetPet/releases 查看。注意 NetPet 的检查请求不走系统代理，只有 TUN 模式的 VPN 才会接管它。
- **“GitHub 暂时限制了请求次数”**：同一 IP 每小时匿名请求有上限（公司/学校共用出口时常见），过一会儿再试。
- **“还没有发布过正式版本”**：仓库里只有预发布版或还没有发布，属于正常情况。

## 系统更新检测
- **“在线检查失败”**：Windows 更新服务（wuauserv）被禁用、公司用 WSUS/组策略管理更新，或网络连不上微软服务器时会这样。可以在 设置 → Windows 更新 里手动检查；公司电脑请联系 IT。
- **检查很慢**：第一次在线检查可能要几分钟，这是 Windows 更新服务本身的速度。检查期间可以关掉这个页面，结果会保存。
- **显示“等待重启”但已经重启过**：有些更新要重启两次。再重启一次后点“只看本机状态”刷新。
- **列表和 Windows 更新页面不完全一样**：这里只列软件更新（含驱动、病毒库），不含可选的功能体验包；被你隐藏的更新也不显示。

## VPN（sing-box）
- **点“连接”提示配置检查没通过**：下方日志里是 `sing-box check` 的原始输出，通常是配置字段写错或版本不匹配（新版 sing-box 改过不少字段名）。请用和配置匹配的 sing-box 版本。
- **连上后马上变成“出错 / 意外退出”**：常见原因是端口被占用（另一个代理软件正在用同一端口），或 TUN 模式没有管理员权限。看日志最后几行。
- **断开后网页打不开**：说明系统代理没恢复。先在 VPN 页再点一次“连接”和“断开”；还不行就打开 设置 → 网络和 Internet → 代理，关闭“使用代理服务器”。日志里会有“恢复系统代理：成功/失败”记录。
- **体检提示“系统代理设置发生了变化”**：VPN 连接/断开后 NetPet 会重新记录基线，一般不会提示；如果你在别处改了代理，提示是正常的。
- **网速统计变成两倍**：NetPet 只统计物理网卡，TUN 虚拟网卡（sing-tun）已被排除。如果仍然偏高，请把日志发给我，并说明网卡名称。

## 启动管理
- **禁用后开机还是自己启动了**：有些软件会在运行时自己把启动项改回来，或者用了“计划任务 / 服务”方式自启。这两种不在启动管理的范围内（和任务管理器“启动应用”一样），请在该软件自己的设置里关闭“开机启动”。
- **想恢复**：在启动管理里点“启用”即可，任务管理器 → 启动应用 里也能看到并恢复，两边是同一个标记。NetPet 从不删除启动项本身。
- **“需管理员”的项目改不了**：这些是对所有用户生效的启动项，修改需要管理员权限。点“打开任务管理器 · 启动应用”处理。
- **列表是空的或提示读取失败**：可能被安全软件拦截了 PowerShell。日志里会有“启动项…”相关记录。
- **⚠ 标记**：只说明路径在 Temp/Public 或用脚本程序启动，不少正常软件也这样，不代表是病毒。不确定的可以先禁用观察，再决定。

## 系统清理清得比以前少
1.3.3 起清理规则更保守，这是有意的：
- 临时文件只删 24 小时以前的，避免删掉正在安装的程序刚解压出来的文件。
- 不再清理 `C:\Windows\Logs`（系统更新和组件日志）。
- `%TEMP%` 和 `%LOCALAPPDATA%\Temp` 是同一个文件夹时只算一次，以前的扫描大小重复计算了。
- 回收站如果没清干净，会如实提示还剩多少文件（以前总是显示成功）。

## 小宠物一会有一会没（v1.3.2 已修）
先点 **右键托盘图标 → 一键复位小宠物**，多数情况当场回来。已找到并修好的原因：
1. **位置跑出屏幕**：旧版启动直接用上次保存的坐标，换显示器/改分辨率/拔副屏后宠物落在屏幕外，进程还在但看不见。现在启动、拖动、改尺寸、显示器变化时都会把位置钳制到当前工作区，至少留 40px 可见，实在找不到就回主屏右下角；每 10 秒还有看门狗检查一次。
2. **托盘误点**：旧版单击托盘就切换隐藏/显示，误点一次宠物就没了。现在单击只在“已隐藏”时恢复显示，正常时弹出菜单。
3. **渲染进程崩溃**：旧版 3D/WebGL 渲染进程崩了只记日志，透明窗口剩一个空白框。现在主进程会重建宠物窗口（1.3.3 起改为 5 分钟内最多 3 次，避免反复崩溃时无限重建；重建后保持原来的鼠标穿透状态），渲染页里 WebGL 上下文丢失时先退回 emoji 宠物。
4. **全屏检测子进程死掉**：旧版 PowerShell 检测进程退出后，最后一次“隐藏”状态会一直卡住。现在检测值连续 2 次一致才翻转（约 6 秒防抖），子进程退出后先恢复显示、5 秒后自动重启检测。
5. 如果复位后还是看不见，检查两点：是否开了“全屏时自动隐藏”且正有全屏应用在运行（复位后会先显示 30 秒，1.3.3 起 30 秒后如果仍在全屏会再次隐藏，退出全屏就回来）；是否开了“鼠标穿透”（宠物在那但点不动，从托盘菜单关闭）。

## v1.3.1 做了哪些防卡死的改动
- 所有系统信息采集（CPU、磁盘、进程、连接等）都放进**独立的采集进程**，带超时；超时会连同它的子进程一起结束并重启，连续超时的项目会暂停 5 分钟。起因：采集库在 Windows 上会在主进程里同步执行 `netstat`、`netsh` 等外部命令，一旦变慢整个程序就会卡住。
- Windows 上的实时网速改用一个只读的轻量查询（Get-NetAdapterStatistics，每秒一次，只统计物理网卡）。
- 启动标记 + 自动安全模式 + 日志。


## 快捷键不起作用（1.4.0）
- 设置页显示“⚠ 已被其他程序占用”：Windows 规定同一个全局快捷键只能被一个程序注册。输入法、截图 / 录屏工具、显卡控制面板常会占用 `Ctrl+Alt+字母`。换一个组合即可，或关闭占用它的程序后在设置页重新选一次。
- 没有提示但按了没反应：确认设置页里选的不是“关闭”；以管理员身份运行的程序处于前台时，普通权限的 NetPet 可能收不到快捷键（Windows 的权限隔离），切到别的窗口再试。
- 宠物被“全屏时自动隐藏”藏起来时按快捷键只会显示 30 秒，之后如果仍在全屏会再次隐藏，这是有意的。

## 设置导入失败 / 导入后和预期不一样（1.4.0）
- “这不是 NetPet 导出的设置文件”：只能导入由“导出设置”生成的 JSON（文件里有 `"format": "netpet-settings"`）。
- 导入后面板密码、VPN 选择没有变：这些是加密的敏感设置，故意不导出也不导入，请在新电脑上重新设置。
- 导入后开机自启没打开：开机自启会修改系统，故意不导入，请在隐私页手动开启。
- 导入时弹窗说“会开启以下监控功能”：说明文件里有你当前关闭的监控开关。选“取消”则什么都不改。
- 安全模式下导入的隐私开关在退出安全模式后会恢复为原来的选择。

## 解锁时提示“密码输错次数太多”（1.4.0）
1 分钟内输错 5 次后会暂时拒绝解锁，等 1 分钟再试。忘记密码见上文“忘记面板密码”。


## 电源方案改了之后想恢复（1.5.0）
1. 首选：主面板 → 温度与节能 → **恢复原设置**（或托盘菜单 → 温度与节能 → 恢复原设置）。它会回到 NetPet 第一次修改之前的电源方案、最大处理器状态和散热方式。
2. NetPet 打不开或备份失效时：以管理员身份打开“命令提示符”，运行 `powercfg -restoredefaultschemes`，所有电源方案会恢复为 Windows 默认值（你自己建的方案会被删除）。
3. 只想恢复最大处理器状态：`powercfg /setacvalueindex SCHEME_CURRENT SUB_PROCESSOR PROCTHROTTLEMAX 100`、`powercfg /setdcvalueindex SCHEME_CURRENT SUB_PROCESSOR PROCTHROTTLEMAX 100`、`powercfg /setactive SCHEME_CURRENT`。
4. 提示“powercfg 返回错误”：部分电脑修改电源设置需要管理员权限，请以管理员身份运行 NetPet 再试。卸载 NetPet **不会**自动恢复电源设置，如需恢复请在卸载前点“恢复原设置”。

## 自动降温不工作（1.5.0）
- 页面上 CPU 温度显示“读不到”：很多电脑（尤其台式机主板、部分笔记本）不向 Windows 提供 CPU 温度，自动降温就不会工作。这是硬件 / 驱动限制。
- 需要“硬件状态监控”开启；暂停监控时也不工作。安全模式下所有自动修改系统的功能都不运行。

## 磁盘整理按钮是灰的 / 提示需要管理员（1.5.0）
- 优化和读取碎片率都需要管理员权限：右键 NetPet → 以管理员身份运行；或点“打开‘碎片整理和优化驱动器’”用 Windows 自带工具。
- 类型显示“未知”的盘（部分 U 盘、虚拟磁盘、RAID）为安全起见一律跳过。
- 用电池时不运行，请接通电源。取消后如果系统的优化仍在进行，可以在“碎片整理和优化驱动器”里查看。

## 病毒查杀的按钮是灰的（1.5.0）
- 装了第三方杀毒软件（如火绒、360、卡巴斯基）并且它在工作时，Microsoft Defender 会进入被动模式，NetPet 不发起扫描，请用那款软件扫描。
- 提示“没有权限”：部分系统或公司电脑的策略要求管理员权限，或 Defender 服务被关闭；可以以管理员身份运行 NetPet，或直接打开 Windows 安全中心。
- 离线扫描会立即重启电脑，请先保存工作。

## 任务管理器里结束不了某个进程（1.5.0）
- 显示 🔒 的是系统关键进程、杀毒软件或 NetPet 自己，NetPet 不允许结束（结束系统进程可能蓝屏或注销）。要退出 NetPet 请用托盘菜单 → 退出软件。
- 提示“拒绝访问”：该进程以管理员或其他用户身份运行，请以管理员身份运行 NetPet 后再试，或使用 Windows 任务管理器。
- 所有结束 / 优先级操作都记在日志里（`%APPDATA%\NetPet\logs`）。

## 界面语言不对 / 有的地方还是中文（1.5.0）
- 设置页 → 语言 选“中文”或“English”可以固定语言；“跟随系统”按 Windows 显示语言（中文以外一律用英文）。
- 健康检查的明细、系统清理的类别说明、启动项来源、连接记录的提示等由系统检查生成的文字目前只有中文，这是已知限制。

## 每周小结没有出现（1.5.0）
- 每周小结在“新的一周第一次检测到你在用电脑”时生成（空闲超过 2 分钟会等你回来）；上一周几乎没有数据时只生成、不发通知。
- 勿扰 / 全屏 / 暂停监控时不发通知，可以在主面板 → 每周小结 里查看，也可以点“立即（重新）生成上周小结”。
