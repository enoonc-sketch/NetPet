# NetPet 技术架构（v1.3）

技术栈：**Electron 37 + TypeScript + React 18 + three.js + SQLite（Node 内置 node:sqlite）**。构建用 esbuild（`node build.mjs`），类型检查用 `tsc --noEmit`（`npm run typecheck`）。
与规范书的差异：TypeScript 为宽松模式（`strict: false`），three.js 的 3D 造型代码类型较松（大量 `any`）；数据库用 Node 内置 SQLite，不需要编译原生模块。

## 目录
```
src/main/        主进程：main.ts（生命周期/IPC/采样）、db.ts、petstate.ts、security.ts、fullscreen.ts
src/preload/     preload.ts（受限 API：on/send/invoke 各有白名单）
src/shared/      petlist.ts、types.ts（主进程与界面共用的类型）
src/renderer/    pet/（宠物窗口）、panel/（单击小面板）、dashboard/（完整窗口 6 页）、pets3d.ts（18 只 3D 宠物）
static/          html + css
tests/unit.ts    状态机与数据库单元测试
build.mjs        打包脚本（输出到 out/）
```

## 分层
| 层 | 位置 |
|---|---|
| UI 展示层 | `dashboard/`、`panel/`（React） |
| 宠物动画层 | `pet/`、`pets3d.ts`（three.js；WebGL 不可用时退回 emoji 宠物） |
| 宠物状态机 | `petstate.ts`：9 个状态，持续时间防抖 + 优先级 + 最短停留 |
| 系统信息采集层 | `main.ts`（tick）+ `systeminformation` |
| 网络统计层 | `main.ts`：A 网卡总流量、C 连接元数据；B 按进程流量**未实现** |
| 系统健康检查层 | `security.ts`、`fullscreen.ts`：只读检查，输出 正常/注意/异常/无法检测 + 依据 + 建议 |
| 本地数据库层 | `db.ts`：7 张表、保留期限、清空、`VACUUM INTO` 备份、损坏自动重建 |
| 权限管理层 | `main.ts` 中的 privacy 开关：每项功能独立开关，关闭即不采集 |
| 设置管理层 | `applyPatch`（白名单校验）+ `settings` 表 |

## Electron 安全措施
contextIsolation、sandbox、禁用 nodeIntegration；preload 只暴露白名单通道；主进程校验消息来源窗口并校验参数；禁止页面跳转与新窗口；拒绝所有权限请求；页面 CSP 为 `default-src 'self'`，脚本只能来自本地文件，不允许内联脚本。

## 子进程管理
PowerShell 检查、全屏检测、systeminformation 的常驻 PowerShell 都在退出时结束（`before-quit`）。
