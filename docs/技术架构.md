# NetPet 技术架构（v1.5.0）

技术栈：**Electron 37 + TypeScript + React 18 + three.js + SQLite（Node 内置 node:sqlite）**。构建用 esbuild（`node build.mjs`），类型检查用 `tsc --noEmit`（`npm run typecheck`）。
与规范书的差异：TypeScript 为宽松模式（`strict: false`），three.js 的 3D 造型代码类型较松（大量 `any`）；数据库用 Node 内置 SQLite，不需要编译原生模块。

## 目录
```
src/main/        主进程
  main.ts          生命周期、窗口、托盘、IPC、采样循环、全局快捷键
  collect.ts / collector.ts   独立采集进程（systeminformation 只在这里调用）
  netmon.ts        Windows 轻量网速采集（常驻只读 PowerShell）
  db.ts            SQLite 数据层（含按天流量 daily）
  petstate.ts / petgeom.ts / guards.ts   状态机、窗口几何、小工具（纯函数）
  security.ts / fullscreen.ts / probe.ts / winupdate.ts / startup.ts / cleaner.ts / memtrim.ts / vpn.ts / selfupdate.ts / extras.ts
  secure.ts        敏感设置加密（safeStorage / DPAPI）
  settingsio.ts    设置导出 / 导入（1.4.0，纯函数）
  logger.ts        本地日志
src/preload/     preload.ts（受限 API：on/send/invoke 各有白名单；on 返回取消订阅函数）
src/shared/      petlist.ts、types.ts、hotkey.ts（快捷键白名单）、report.ts（流量日报补齐与汇总）
src/renderer/    pet/（宠物窗口）、panel/（单击小面板）、dashboard/（完整窗口 10 页）、pets3d.ts（18 只 3D 宠物）
static/          html + css（深色 / 浅色主题跟随系统）
tests/unit.ts    单元测试（纯逻辑 + 数据库 + 清理）
build.mjs        打包脚本（输出到 out/）
.github/workflows/   ci.yml（Windows 上类型检查 + 测试 + 打包）、release.yml（标签发布，可选签名）
```

## 分层
| 层 | 位置 |
|---|---|
| UI 展示层 | `dashboard/`、`panel/`（React）；`common.tsx` 提供加载 / 出错 / 空状态、折线图、柱状图、中文错误提示 |
| 宠物动画层 | `pet/`、`pets3d.ts`（three.js；WebGL 不可用时退回 emoji 宠物；缩略图只生成一次并立即归还 WebGL 上下文） |
| 宠物状态机 | `petstate.ts`：9 个状态，持续时间防抖 + 优先级 + 最短停留 |
| 系统信息采集层 | `collect.ts` → `collector.ts`（独立 utilityProcess，超时即重启）；`netmon.ts` |
| 网络统计层 | `main.ts`：A 网卡总流量（按天累计，周报 / 月报）、C 连接元数据；B 按进程流量**未实现** |
| 系统健康检查层 | `security.ts`：只读检查，输出 正常/注意/异常/无法检测 + 依据 + 建议；每项单独兜底 |
| 本地数据库层 | `db.ts`：7 张表、保留期限、清空、`VACUUM INTO` 备份、损坏自动重建 |
| 权限管理层 | privacy 开关：每项功能独立开关，关闭即不采集；密码锁在主进程强制（`LOCKED_CH`） |
| 设置管理层 | `applyPatch`（白名单校验）+ `settings` 表；导入导出经 `settingsio.ts` 再过一遍白名单 |

## IPC 约定
- 渲染页 → 主进程只能走 `preload.ts` 白名单里的通道；主进程 `handle()` 再校验：消息必须来自 NetPet 自己的三个窗口；上锁且未解锁时拒绝 `LOCKED_CH` 里的敏感通道（报错 `locked`）。
- 1.4.0 新增通道：`get-traffic-report`（`{days: 7|30}`）、`export-settings`、`import-settings`，三者都受密码锁保护。
- 渲染页用 `common.tsx` 的 `errMsg()` 把 `locked`、`too-many-attempts`、`busy` 等错误翻译成中文提示。

## Electron 安全措施
contextIsolation、sandbox、禁用 nodeIntegration、禁用 webview 与拼写检查；preload 只暴露白名单通道；主进程校验消息来源窗口并校验参数；禁止页面跳转、新窗口和嵌入 webview；拒绝所有权限请求与权限查询；页面 CSP 为 `default-src 'self'; object-src 'none'; base-uri 'none'; form-action 'none'`，脚本只能来自本地文件，不允许内联脚本。所有 PowerShell 调用都用 `-EncodedCommand`，可变内容以 Base64 传入，不拼接命令。

## 子进程管理
PowerShell 检查、全屏检测、网速采集器、采集进程、sing-box 都在退出时结束（`before-quit`），网速采集器在退出后不会再被重新拉起；全局快捷键在退出时注销。
